# วิจัยสีเว็บหลักมั่งมีพลัส (รอบใหม่)

วันที่: 20 ตุลาคม 2026 (2569)
ขอบเขต: สีของเว็บหลักต้นแบบ v3 เทียบ v2 กับสีของแบรนด์และแอปจริง
สถานะ: ข้อเสนอสำหรับเจ้าของ ยังไม่ได้ทดสอบกับลูกค้า และยังไม่ได้แก้เว็บจริง

## สรุปสั้น

**แนะนำให้ใช้ชุดสีเดียวกับแบรนด์และแอป: เขียวเข้มเป็นพื้นหลัก และทองของเหรียญในโลโก้เป็นสีปุ่มหลัก** ส่วนเขียวมะนาวของ v2 ควรเลิกใช้ เหตุผลมี 3 ข้อ

1. เขียวมะนาวไม่มีอยู่ในโลโก้และใน design tokens ของแอป ลูกค้าที่สมัครแล้วจะเจอสีอีกชุดหนึ่งในแอป
2. เขียวมะนาวบนพื้นขาวมี contrast แค่ 1.16:1 จึงใช้เป็นปุ่มบนพื้นขาวไม่ได้ ต้องสลับไปใช้สีปุ่มอีกสี ปุ่มหลักเลยมีสองหน้าตา
3. ไม่พบหลักฐานที่น่าเชื่อถือว่าสีใดสีหนึ่งเพิ่มยอดขาย SaaS สิ่งที่มีหลักฐานกว่าคือความสม่ำเสมอของแบรนด์ contrast ที่อ่านได้ และสีเน้นสีเดียวที่ใช้กับปุ่มหลักเท่านั้น

ไม่แนะนำให้ใช้เขียว LINE (#06C755) เป็นปุ่มหลัก ตัวอักษรขาวบนสีนี้ได้ 2.26:1 ซึ่งไม่ผ่าน WCAG AA และสีนี้ใกล้เขียวของเราเองจนปุ่มไม่เด่นจากพื้น

### สิ่งที่หลักฐานบอก และยังไม่บอก

- **ไม่มีสีที่ดีที่สุดสำหรับความไว้ใจในทุกบริบท** ความเชื่อเดิมว่า “น้ำเงิน = น่าเชื่อถือ” ขัดกับ C1 ซึ่งพบว่าเขียวและเทาได้ความไว้ใจสูงกว่าน้ำเงิน ผลขึ้นกับวัฒนธรรมและบริบท จึงไม่มีเหตุผลต้องเปลี่ยนแบรนด์ไปน้ำเงินตามคู่แข่ง
- **เขียวมีความหมายบวกในบริบทไทยบางแบบ** (ความปลอดภัย ความสุข: C3, C4) แต่ไม่ได้ดีเสมอ (C5) และ C1 ชี้ว่าความอิ่มสีสูงลดความไว้ใจ จึงควรใช้เขียวเข้มไม่จัดจ้าน และพื้นอ่อน
- **ทองเข้ากับความหมายของชื่อ “มั่งมี” และเหรียญในโลโก้** ทองและเหลืองในไทยมีความหมายเรื่องความรุ่งเรืองและสิ่งมีค่า และเหลืองเกี่ยวกับสถาบันตามสีประจำวัน ข้อนี้เป็นความรู้ทางวัฒนธรรม ไม่ใช่ผลวัดจากผู้บริโภค ใช้ทองเป็นสีเน้นจุดเล็ก ไม่ใช้เหลืองสดเป็นพื้นผืนใหญ่
- **ประมาณ 5–8% ของผู้ชายไทยในตัวอย่างที่ศึกษาแยกแดงกับเขียวได้ยาก** (C6) แบรนด์เราเป็นเขียว สถานะ “อ่านผิด/ผิดพลาด” ที่เป็นแดงต้องมีคำกำกับเสมอ ไม่ใช้สีอย่างเดียว (C7)
- **หลักฐานที่ยังไม่มี**: ไม่มีผลทดสอบว่าเจ้าของกิจการไทยชอบชุดสีไหน หรือชุดไหนทำให้สมัครมากขึ้น และยังไม่ได้ตรวจสีหน้าเว็บคู่แข่งโดยตรง (เว็บถูกบล็อกจากสภาพแวดล้อมนี้)

กติกา:

1. **ทองใช้กับ 3 อย่างเท่านั้น:** ปุ่มหลักบนพื้นเข้ม คำเน้นในหัวเรื่องบนพื้นเข้ม และเหรียญในโลโก้ ห้ามใช้ทองเป็นตัวอักษรบนพื้นขาว (1.44:1)
2. **หน้าจอหนึ่งมีปุ่มทองหรือปุ่มเขียวทึบปุ่มเดียว** ปุ่มอื่นเป็นเส้นขอบ ตาม isolation effect (C10) และ[มาตรฐาน UX ไทย](../guidelines/thai-ux-standard.md) ข้อ 2.1
3. **สัดส่วนโดยประมาณ:** พื้นขาวและเขียวอ่อนเป็นส่วนใหญ่ เขียวเข้มเฉพาะ hero แถบ ENTERPRISE และส่วนปิดหน้า ทองเป็นจุดเล็ก ไม่ใช้พื้นสีจัดผืนใหญ่ (C1: พื้นอิ่มสีน้อยได้ความไว้ใจมากกว่า; รีวิว UX ข้อ 6)
4. **สีไม่สื่อความหมายเดี่ยว ๆ:** สถานะทุกอันมีคำ (“รอตรวจ”, “ยืนยันแล้ว”, “อ่านผิด”) ป้ายบทบาท (พนักงาน / AI / คุณ) แยกด้วยรูปแบบด้วย ไม่ใช้สีเดียวกับสถานะรอตรวจ
5. **ป้ายต้นแบบ** (เช่น “ตรวจราคาก่อนเผยแพร่”, “[รอรีวิวลูกค้าจริง]”) ใช้กรอบเส้นประสีเทา ไม่ใช้สีเหลืองซ้ำกับสถานะรอตรวจ
6. **ปุ่มไป LINE ไม่ใช้เขียว LINE และไม่ใช้โลโก้ LINE** จนกว่าจะอ่านข้อกำหนด Social Plugin ฉบับเต็มแล้ว ใช้คำ “เริ่มใช้งานผ่าน LINE” แทน
7. **โลโก้ใช้เหรียญงอกเงยจากแอป** ไม่ใช้โลโก้แท่ง 4 แท่งของ v2

## 5. วิธีพิสูจน์กับลูกค้า

ใช้รอบทดสอบความเข้าใจที่เสนอใน[รีวิว UX](mangmee-main-website-saas-ux-review-2026-10-20-th.md) (เจ้าของกิจการ 6–8 คน) โดยเพิ่ม:

- ดูหน้าจอแรก 5 วินาทีแล้วถามว่า “ปุ่มที่ควรกดคือปุ่มไหน” นับว่าชี้ปุ่มหลักถูกกี่คน เทียบ A กับ B
- ถามความรู้สึกเรื่องความน่าเชื่อถือหลังทำงานเสร็จ ไม่ถามก่อน และไม่ถามแค่ “ชอบสีไหน”
- มีผู้ร่วมอายุมากกว่า 45 ปีอย่างน้อย 2 คน (C2: ความชอบสีต่างตามอายุ)
- ตรวจบนมือถือจริงกลางแดดหรือในร้านที่แสงจ้า และจำลองตาบอดสีแดง-เขียว (deuteranopia) ก่อนเผยแพร่

## 6. สถานะ

- แสดงชุด A เทียบ B และ C บน canvas ต้นแบบ v3 ในกรอบ “ชุดสีที่เทียบ”
- ใช้ชุด A กับกรอบหน้าแรกและหน้าราคาแล้วในรอบ 2 (20 ต.ค. 2026) เจ้าของเปลี่ยนกลับได้ถ้าเลือกชุดอื่น
- ไม่ได้แก้แอปหรือ design tokens
