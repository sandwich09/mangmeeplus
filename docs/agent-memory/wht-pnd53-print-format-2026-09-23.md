# Agent Memory: WHT 50 ทวิ and ภ.ง.ด.53 print format

Status: Merged to develop (PR #749) and main (PR #750); CI follow-up in progress. Not deployed.
Owner: Codex
Scope: Official Revenue Department paper masters, Thai fill-in font, address and field layout, print QA.
Decisions: 50 ทวิ uses the RD PDF master at https://rd.go.th/fileadmin/tax_pdf/withhold/approve_wh3_081156.pdf. The delivered PDF contains two copies of the original master. Fill-in text is rasterized in Noto Sans Thai on top of the official static form so recipients need no local Thai font. Legacy JSON address strings are parsed into printable Thai address text; malformed JSON stops issuance. Unsupported or dividend income categories stop before printing an incorrect row. Blank and automatic signature modes remain. ภ.ง.ด.53 retains the RD main and annex masters at https://rd.go.th/7064.html; long fill-in text now fits inside its field width instead of stretching short values or crossing adjacent labels. Legacy JSON payee addresses are normalized before export; malformed values are refused.
Artifacts: `apps/api/src/modules/tax/assets/rd-wht50bis.pdf`, `apps/api/src/modules/tax/domain/logic/wht-certificate-pdf.logic.ts`, `apps/api/src/modules/tax/domain/logic/pnd53-official-form.logic.ts`, the two print-format specs/plans. QA PDFs: `/Users/thawatchai/.codex/visualizations/2026/09/23/01a0cd97-0baf-79c2-8256-23d5433fb9b2/tax-print-qa/`.
Verification: Rendered 50 ทวิ and ภ.ง.ด.53 sample pages to PNG and compared visually with their RD masters; no serialized address, overlapping tax ID or amount columns in the sample. 50 ทวิ focused test: 3 passed. ภ.ง.ด.53 export focused test: 8 passed. API SWC build and TypeScript noEmit passed; build copied all three RD masters into the production output path.
