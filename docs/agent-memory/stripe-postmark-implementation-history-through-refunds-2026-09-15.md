## Live dahlia credit-note preview fix — 2026-09-23

- Root cause: production Stripe API `2026-08-26.dahlia` refuses the amount-based credit-note params, so every in-app refund failed as `CONTROL_REFUND_SOURCE_CHANGED` ("หลักฐานการคืนเงินเปลี่ยนหรือยังไม่ครบ") because `refundPreview` maps any Stripe error to review-required.
