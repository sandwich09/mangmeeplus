They were old CommonJS output shadowing current `.ts` sources; under Turbopack they were silently bundled (or missing for newer modules → build errors). Package builds output to `dist/` only.

Root cause: Turbopack merges `paths` from the extended `tsconfig.base.json` (which maps contracts to `src/index.ts`), while tsc/webpack let the child's `paths` replace the parent's and resolved contracts via package exports to `dist/`. The explicit entry pins both resolvers to `dist`, matching pre-upgrade behavior. Dev flow unchanged: contracts already had to be built for types.
- No middleware/proxy rename needed (no middleware.ts). Async params already migrated on 15.5. `pnpm start` (`next start`) unchanged — AWS runtime path identical.
