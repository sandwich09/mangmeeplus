# เว็บหลัก v3 ที่ทำในแอป

สถานะ: ทำโค้ดแล้ว ยังไม่เผยแพร่และยังไม่ได้ตรวจด้วยเบราว์เซอร์จริงในรอบนี้

- หน้า `/` เป็นเว็บสาธารณะตาม Main / Home-Phone: ภาพหลัก วิธีใช้ 3 ขั้น ราคา งานที่ช่วย น้องมั่งมี เอกสารตัวอย่าง ความปลอดภัย คำถาม และติดต่อ รวมตารางเทียบราคาและตัวช่วยเลือกจาก Pricing ไว้ที่ `#pricing` ในหน้าเดียว
- ผู้ที่เข้าระบบแล้วก็เปิดหน้าเว็บหลักได้ ปุ่มเข้าสู่ระบบไป `/login` ตามเดิม เริ่มใช้งานไป `https://lin.ee/U5oRBx1` ตามต้นแบบ ทีมงานไป LINE `@mangmeeplus` นโยบายไป `/privacy` และ `/terms`
- ใช้ภาพเว็บพีทั้ง 17 ภาพจาก canvas เป็นไฟล์จริงใน `apps/web/public/home/` ไม่ฝังภาพใน HTML ใช้ IBM Plex Sans Thai และ Outfit ที่แอปมีอยู่แล้ว ไม่เพิ่มฟอนต์จากข้างนอกหรือผ่อน CSP
- แชต LINE และภาพเปิดร้านเลื่อนช้า หยุดแล้วค้างภาพ กดเล่นต่อได้ เครื่องที่ลดการเคลื่อนไหวแสดงภาพนิ่งและเลื่อนดูเองได้ เอกสารกดขยายเป็นหน้าต่าง กดปิดหรือ Escape ได้ ตัวช่วยเลือกใช้จำนวนคน ใบเสร็จ สาขา และงานภาษี
- ข้อความ ราคา ตาราง และคำถามส่งมาจากเซิร์ฟเวอร์ อ่านได้แม้ยังไม่ทำงาน JavaScript ราคาและจำนวนในส่วนราคา JSON-LD และ wiki ใช้ `billingOffer` / `PLAN_TIER_PRESETS` ไม่แก้ราคาในระบบขาย ราคาปกติไม่ใช่ใบเสนอราคาเฉพาะร้าน
- Title ใช้ข้อความที่เจ้าของเลือก มี canonical, Open Graph, Twitter และ JSON-LD Organization / WebSite / SoftwareApplication / FAQPage ซึ่งใช้คำถามชุดเดียวกับหน้าจอ หน้าเดียวไม่มี BreadcrumbList
- มี `/llms.txt` และ `/llms-full.txt` เป็นข้อความไทยและอังกฤษ เปิดอ่านได้จริงและเก็บแคชได้ ไม่ซ่อนข้อความ SEO ในหน้า มี robots และ sitemap เฉพาะเนื้อหาสาธารณะ ไม่รับรองอันดับ Google หรือการถูก AI อ้างอิง

## ที่เปลี่ยนจากภาพ และเหตุผล

- ไม่ใส่ 91–97%, “ทุกใบ” และ 0 ยอดผิด: README เล่าผล แต่ไม่มีชุดข้อมูลและวิธีทำซ้ำที่ตรวจในรอบนี้ จึงไม่ใช้ตัวเลขเป็นคำรับรอง
- ตัวเลข 500 ใบระบุว่าเป็นรายเดือน และ 30 คนระบุว่าเป็นแพ็กเกจธุรกิจ ไม่อ้างเป็นเพดานของร้านทุกกรณี เพราะรายปีได้ใบเสร็จเป็นก้อนเดียวและร้านอาจมีเงื่อนไขเฉพาะ
- ไม่สัญญาเครดิตแชต 80 ต่อเดือนตายตัว: README ระบุว่ายังต้องตรวจนโยบายขาย และโค้ดปรับได้รายร้าน ใช้ข้อความตามเครดิตของร้านแทน
- รวมคำถามเรื่องราคาที่ซ้ำไว้กับคำถามท้ายหน้า และเขียนเรื่องเพิ่มจำนวน/เปลี่ยนแพ็กเกจให้ตรวจราคา เงื่อนไข และวันที่เริ่มใช้ก่อนจ่าย ไม่รับรองว่าเปลี่ยนได้ทันทีทุกกรณี เพราะโค้ดมีเงื่อนไขของการเปลี่ยนและยอดขั้นต่ำ
- ไม่ใส่โปรโมชั่น รีวิว หรือป้ายต้นแบบ ใช้คำรายปี “เท่ากับ 10 เดือน” และ VAT ตามเจ้าของ: “ราคานี้ยังไม่มี VAT ออกใบเสร็จรับเงินให้”
- แถบชื่อความสามารถเลื่อนดูเองได้แทนเลื่อนวนตลอดเวลา ภาพตัวอย่างระบุว่าเป็นตัวอย่างในคำอธิบายภาพ ไม่อ้างว่าเป็นข้อมูลลูกค้า
- ใช้ช่องว่างและความกว้างของเว็บการตลาดตาม artboard ตามคำสั่งรอบนี้ ซึ่งเจาะจงกว่ากติกาหน้าระบบหลังเข้าสู่ระบบ แผน SEO เดิมอ้าง repo เว็บเก่า รอบนี้ใช้ root ใน Next ตามคำสั่งเจ้าของ
- ใน checkout นี้มี approved help v4 และ draft v5 ไม่มี `product-help-draft-cards.ts` จึงเทียบข้อเท็จจริงกับ approved pack ที่มีอยู่และโค้ด ไม่เปลี่ยนคำตอบ LINE
- ตรวจพบช่องแนบไฟล์ 50 ทวิ นอกระบบใน `ExpenseCertificateCard.tsx` และช่วงวันที่ใน `DashboardPages.tsx` แล้ว ใช้ข้อยืนยันวันขึ้น Production ของเจ้าของใน brief ไม่แก้สองหน้าระบบนี้

## ให้ตรวจบน proof stack ก่อนเผยแพร่

เปิด `/` โดยไม่เข้าระบบและขณะเข้าระบบ ที่ 375 / 390 / 1280 / 1440 / 1556 px รวม Safari บน iPhone: เลื่อนหน้าได้ ไม่ล้นข้าง ปุ่ม LINE / เข้าสู่ระบบ / นโยบายถูกทาง แชตหยุดค้างและเล่นต่อได้ ขยายเอกสารแล้ว Escape ปิดและคืนโฟกัส ทดลองรายปีและคำตอบทั้ง 4 ข้อของตัวช่วยเลือก ตรวจ FAQ กับ JSON-LD และเปิด llms ทั้งสองไฟล์ ตรวจใบ 50 ทวิ นอกระบบแบบแนบไฟล์บน release ที่จะขึ้นจริง

มี journey `e2e/journeys/public-home.journey.spec.ts` สำหรับ 375 และ 1440 ในโครงการ browser เดิม ผู้ควบคุมเป็นคนรัน รอบนี้ไม่เปิด server, browser, Docker หรือปล่อยระบบ
