#### Hero (หน้าจอแรก)

- เหนือหัวเรื่อง: มั่งมีพลัส (MangmeePlus) · ตัวช่วยจัดการใบเสร็จและค่าใช้จ่ายของร้าน
- H1: **ส่งใบเสร็จผ่าน LINE ให้ AI ช่วยอ่าน** / บรรทัดสีเขียวมะนาว: **คุณตรวจ แล้วค่อยยืนยัน**
- ข้อความ 3 บรรทัด:
  - พนักงานถ่ายรูปใบเสร็จส่งในแชต
  - AI อ่านผู้ขาย วันที่ และยอดเงิน แล้วเตรียมเป็นรายการ
  - คุณตรวจ แก้ และกดยืนยันเอง ใบเบิกพนักงานก็จบในที่เดียว
- ปุ่มหลัก: **เริ่มใช้งานผ่าน LINE** ↗ (เปิดแท็บใหม่)
- ปุ่มรอง: ดูวิธีใช้ 3 ขั้น → `#how`
- ใต้ปุ่ม: **กดแล้วจะเปิด LINE ของมั่งมีพลัส** สมัคร ตั้งค่าร้าน แล้วเลือกแพ็กเกจ · ราคาเริ่ม 249 บาท/เดือน · ไม่มีทดลองใช้ฟรี · ดูราคาทั้งหมด
- 3 จุดมั่นใจ: คนตรวจทุกรายการก่อนยืนยัน · ใบเสร็จ ใบเบิก และหลักฐาน อยู่ในที่เดียว · ดูแลโดย บริษัท มั่งมียั่งยืน จำกัด
- ภาพ (ภาพจำลอง · ข้อมูลสมมติ) “จากรูปหนึ่งใบ ถึงรายการที่ยืนยันแล้ว”:
  1. ส่งรูปใน LINE — ป้าย **พนักงาน** — แชต “ใบเสร็จ อรุณซัพพลาย · ส่งรูปแล้ว 09:41”
  2. AI อ่านและเตรียมรายการ — ป้าย **AI** — ผู้ขาย อรุณซัพพลาย · วันที่ 20 ต.ค. 2569 · ยอดรวม ฿1,284.00 · สถานะ รอตรวจ
  3. ตรวจกับรูปต้นฉบับ แล้วยืนยัน — ป้าย **คุณ** — ค่าอุปกรณ์ร้าน ฿1,284.00 · ยืนยันแล้ว

ทำไมช่วยขาย: v2 บอกหมวดงาน แต่ไม่บอกว่าเจ้าของได้อะไรต่างจากการส่งรูปในแชตทั่วไป หัวเรื่องนี้บอกทั้งงาน (ส่งใบเสร็จ) ช่องทาง (LINE) ตัวช่วย (AI) และการควบคุม (คุณตรวจ) ในประโยคเดียว ภาพเล่าความต่อเนื่อง “ต้นฉบับ → รอตรวจ → ยืนยันแล้ว” พร้อมบทบาทในภาพเดียว ตามข้อแก้ 1 ของ [UX](../../../research/mangmee-main-website-saas-ux-review-2026-10-20-th.md) ราคาเริ่มต้นและ “ไม่มีทดลองใช้ฟรี” อยู่ข้างปุ่มตามข้อแก้ 4 เพื่อไม่ให้คนกดแล้วผิดหวัง หัวเรื่องใช้ชุด A ของ [GL ข้อ 6](../../../research/mangmee-thai-main-website-guideline-2026-10-20-th.md) ชุด B (“ใบเสร็จเข้าทาง LINE รายจ่ายเป็นรายการให้ตรวจ”) เก็บไว้ทดสอบเทียบ

### 1.5 JSON-LD หน้าแรก

ใส่เป็น `<script type="application/ld+json">` หนึ่งก้อนใน HTML ที่ server ส่งมาเลย (ไม่สร้างด้วย JavaScript) ข้อความทุกช่องต้องตรงกับที่เห็นบนหน้า

- คง Organization, WebSite, SoftwareApplication และ WebPage/FAQPage ตามที่เว็บปัจจุบันมีอยู่ ([SEO-E ตารางหน้าเว็บ](../../../research/mangmee-google-seo-evidence-2026-10-20-th.md)) ไม่เพิ่ม entity ซ้ำ

**กดปุ่มแล้วจะเกิดอะไรขึ้น** — 4 ขั้น จากกดปุ่ม ถึงใบเสร็จใบแรก [ตรวจกับขั้นตอนสมัครจริงก่อนเผยแพร่]

3. เลือกแพ็กเกจและรอบจ่าย — รายเดือน หรือรายปี
4. ส่งใบเสร็จใบแรก — แล้วตรวจและยืนยันรายการแรก

## 4. ความเร็วและการอ่านบนมือถือ (สำหรับคนทำเว็บจริง)

- HTML ส่งข้อความทั้งหมดมาเลย หัวเรื่องอ่านได้ทันที ไม่รอ animation ([GL ข้อ 11](../../../research/mangmee-thai-main-website-guideline-2026-10-20-th.md))
- ภาพหลักทำด้วย HTML/CSS ไม่มีรูปใหญ่ในหน้าจอแรก ภาพหน้าจอจริงที่จะใส่ภายหลังใช้ WebP/AVIF ระบุ `width`/`height` และ `loading="lazy"` นอกหน้าจอแรก
- ฟอนต์: Anuphan + Inter จาก Google Fonts ใช้ `display=swap` และ preconnect ถ้าวัดแล้วช้า ให้ self-host เฉพาะน้ำหนักที่ใช้
- JavaScript มีแค่ปุ่มสลับรายเดือน/รายปี ตัวช่วยเลือก และเมนูมือถือ FAQ ใช้ `<details>` ไม่ต้องใช้ JavaScript
- เป้าหมาย Core Web Vitals (field p75): LCP ≤ 2.5 วินาที, INP ≤ 200 ms, CLS ≤ 0.1 วัดจริงด้วย PageSpeed/Lighthouse mobile ก่อนเผยแพร่ ถ้าไม่มีข้อมูล field ให้เขียนว่าข้อมูลไม่พอ ([SEO-E ข้อ 3](../../../research/mangmee-google-seo-evidence-2026-10-20-th.md))
- การอ่านภาษาไทย: เนื้อหา 17 px (มือถือ) / 18 px (จอกว้าง), line-height 1.7, H1 34 px (มือถือ) / 54 px (จอกว้าง) ตามช่วงใน [GL ข้อ 8](../../../research/mangmee-thai-main-website-guideline-2026-10-20-th.md) ไม่ยืดช่องไฟตัวอักษรไทย
- สีที่ใช้ (เขียวจาก v2): เขียวเข้ม `#004B2C`, เขียว `#007A39`, เขียวมะนาว `#D2FF43` (ปุ่มหลักบนพื้นเขียวเข้มและจุดเน้น), ตัวอักษร `#10291B`, ตัวอักษรรอง `#3F5247`
- Contrast ที่คำนวณได้ (ต้องตรวจซ้ำในเบราว์เซอร์จริง): ตัวอักษร `#10291B` บนขาว ≈ 15:1; ตัวอักษรรอง `#3F5247` บนขาว ≈ 8:1; ลิงก์ `#006B32` บนขาว ≈ 6.6:1; ปุ่มขาวบน `#007A39` ≈ 5.5:1; `#D2FF43` บน `#004B2C` ≈ 9:1

## 5. BreadcrumbList (ใช้เมื่อมีหน้าย่อยจริงเท่านั้น)

หน้าแรกหน้าเดียวไม่ต้องมี BreadcrumbList เพราะไม่มีลำดับชั้นให้บอก ถ้าเจ้าของอนุมัติหน้าย่อยตาม “งานภายหลัง” ใน [SEO-P](../../../plans/mangmee-google-seo-implementation-plan-2026-10-20-th.md) (เช่น หน้าราคาหรือคู่มือส่งใบเสร็จ) ให้ใช้แบบนี้ในหน้าย่อยนั้น พร้อม URL 200, canonical ของตัวเอง และอยู่ใน sitemap

```json
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {"@type": "ListItem", "position": 1, "name": "มั่งมีพลัส", "item": "https://mangmeeplus.com/"},
    {"@type": "ListItem", "position": 2, "name": "ราคาแพ็กเกจ", "item": "https://mangmeeplus.com/pricing"}
  ]
}
```

`/pricing` เป็นตัวอย่าง URL ยังไม่ได้ตัดสินใจ

## 6. ร่าง llms.txt (ทางเลือก ไม่เร่งด่วน)

แผน SEO ไม่ได้ให้ทำเรื่องนี้ก่อน Google ระบุว่า `llms.txt` ไม่เพิ่มหรือลดอันดับใน Search ([SEO-E ข้อ 3](../../../research/mangmee-google-seo-evidence-2026-10-20-th.md), [GL F2](../../../research/mangmee-thai-main-website-guideline-2026-10-20-th.md)) และยังไม่มีหลักฐานว่า ChatGPT, Gemini หรือ Perplexity ใช้ไฟล์นี้เลือกแหล่งอ้างอิง สิ่งที่ช่วย AI อ้างเราได้จริงคือข้อความบนหน้าในหัวข้อ 1.3 และ 1.4 ร่างนี้เก็บไว้ถ้าเจ้าของอยากวางไฟล์ที่ `/llms.txt` ต้นทุนต่ำ แต่ต้องอัปเดตทุกครั้งที่ราคาเปลี่ยน

