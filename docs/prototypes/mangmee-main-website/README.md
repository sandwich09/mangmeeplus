# มั่งมีพลัส — ต้นแบบเว็บหลัก v2

จัดทำ 20 ตุลาคม 2026 เพื่อพิจารณาเนื้อหาและ layout จาก [guideline เว็บหลัก](../../research/mangmee-thai-main-website-guideline-2026-10-20-th.md)

เปิด `preview.html` ในเบราว์เซอร์เพื่อสลับ v1/v2 และเดสก์ท็อป/มือถือ หรือเปิด `index.html` เพื่อดู v2 หน้าเต็ม รุ่นแรกเก็บใน `index-v1.html` ไฟล์เป็น HTML/CSS/JS ธรรมดา ไม่มีขั้นตอนติดตั้งหรือ build

v2 เพิ่มน้ำหนักสีเขียวเข้ม เขียวมะนาว และเหลือง รวมทั้งแก้ช่องว่างการนำเสนอฟีเจอร์จาก v1 ตรวจแคตตาล็อกสาธารณะจริงเมื่อ 20 ต.ค. 2026 เวลา 16:40 น.: 17 feature keys ร่วมทุกแพ็กเกจ จัดเป็น 6 กลุ่มอ่านง่าย; Enterprise เพิ่ม 2 keys สำหรับ ภ.ง.ด.53 และ 50 ทวิ ดู [แผนที่ฟีเจอร์กับเนื้อหา](../../evidence/main-website-prototype-2026-10-20/v2/feature-content-map.json) ซึ่งระบุความครอบคลุมสิทธิ์ขาย ไม่ใช่ผลทดสอบความพร้อมของทุกขั้นตอนจริง

หากต้องการพรีวิวผ่าน HTTP ให้รันจาก root ของ repository:

```sh
python3 -m http.server 43821 --bind 127.0.0.1 --directory docs/prototypes/mangmee-main-website
```

แล้วเปิด `http://127.0.0.1:43821/preview.html` และกด Ctrl+C ในเทอร์มินัลเมื่อดูเสร็จ

## ลำดับเนื้อหา

1. หน้าแรก: “ใบเสร็จและเบิกจ่าย ให้มั่งมีช่วยจัดการ” พร้อมปุ่มเริ่มผ่าน LINE ปุ่มดูตัวอย่าง และเข้าสู่ระบบ
2. ตัวอย่างกดดูได้ 3 ขั้นตอน: ส่งเอกสาร → AI เตรียมข้อมูล → คนตรวจและยืนยัน
3. ฟีเจอร์ 6 กลุ่ม: ค่าใช้จ่ายและใบเสร็จ, เบิกคืน, เอกสารและลายเซ็น, AI ทาง LINE, ทีม/สาขา/สิทธิ์, ภาพรวมและแจ้งเตือน พร้อมสิทธิ์เอกสารเพิ่มเติมของ Enterprise
4. งานของเจ้าของกิจการและทีมพนักงาน
5. การตรวจเทียบเอกสารต้นฉบับ แก้ไขข้อมูล และบทบาทผู้ยืนยัน
6. แพ็กเกจ 4 ระดับ สลับรายเดือน/รายปี พร้อมยอดเรียกเก็บจริงต่อรอบและโควตา
7. คำถามที่พบบ่อย ปุ่มเริ่มใช้งาน และข้อมูลติดต่อ

## สิ่งที่ทดลองกดได้

- สลับขนาดหน้าจอในแถบพรีวิว
- สลับ v1 สีอ่อนเดิมกับ v2 สีชัดและเนื้อหาครอบคลุมขึ้น
- สลับราคาปกติรายเดือน/รายปี โดยรายปีรับโควตาทั้งก้อน ไม่เติมใหม่ทุกเดือน
- เมนูบนมือถือและลิงก์ข้ามไปแต่ละส่วน
- เลือกขั้นตอนตัวอย่าง กดขั้นตอนถัดไป และเริ่มตัวอย่างใหม่
- เปิด/ปิดคำถามที่พบบ่อย
- เลือกแพ็กเกจเพื่อดูหน้าต่างอธิบาย ปิดด้วยปุ่ม × หรือ Escape

ภาพเอกสารและหน้าจอทั้งหมดเป็นข้อมูลสมมติ ปุ่ม LINE และเข้าสู่ระบบเป็นลิงก์ไปบริการจริงในแท็บใหม่ ไม่มีการสมัคร อัปโหลด ชำระเงิน หรือเรียก API ในต้นแบบนี้ v2 ใช้ snapshot จากแคตตาล็อกสาธารณะจริง แสดงราคาปกติ ไม่รวมโปรโมชั่นชั่วคราว; v1 ใช้ข้อมูลเว็บไซต์ในเครื่อง ทั้งสองเป็นต้นแบบ ต้องตรวจข้อมูลใหม่ก่อนเผยแพร่

ฟอนต์ Anuphan/Inter โหลดจาก Google Fonts เมื่อมีอินเทอร์เน็ต และมีฟอนต์สำรองในเครื่อง การตรวจครั้งนี้ใช้ Chrome ผ่าน local HTTP; การเปิด `file://` ผ่านเครื่องมือเบราว์เซอร์ถูกจำกัดโดย URL policy จึงไม่ได้ตรวจโหมดไฟล์โดยตรง
