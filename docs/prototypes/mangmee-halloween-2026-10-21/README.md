# มั่งมี Halloween — Character prototypes

ต้นแบบภาพนิ่ง 4 แบบ สร้างวันที่ 21 ตุลาคม 2026 ด้วย built-in image_gen โดยอ้างอิงน้องมั่งมี Halloween ที่ผู้ใช้เห็นในแชตแล้ว ใช้สีเขียว ส้ม ม่วง และโบชมพูให้เป็นชุดเดียวกัน

| ภาพ | ขนาด | จุดที่เหมาะสำหรับลองวาง |
| --- | --- | --- |
| [น้องมั่งมีขี่ไม้กวาด](mangmee-broom.png) | 1536 × 1024 | พื้นที่ว่างด้านข้างส่วนเปิดหน้า |
| [น้องมั่งมีโผล่ทักทาย](mangmee-peeking.png) | 1312 × 1199 | ขอบบนการ์ดหรือท้ายหน้า |
| [ผีน้อย](friendly-ghost.png) | 1236 × 1273 | มุม section หรือข้าง FAQ |
| [ฟักทองน้อย](friendly-pumpkin.png) | 1236 × 1273 | มุมการ์ดหรือท้ายหน้า |

ทุกไฟล์เป็น PNG มี alpha โปร่งใส เก็บต้นฉบับโดยไม่เปลี่ยนพิกเซลหลังสร้าง ตรวจภาพทั้ง 4 แบบแล้ว และตรวจช่อง alpha มุมโปร่งใส และ SHA-256 ของไฟล์ที่คัดลอกผ่าน ดู [หลักฐานตรวจ](verification.json)

## แนวทางใช้งาน

คงเนื้อหา ลำดับหน้า ราคา ลิงก์และปุ่มเดิม ตกแต่งในพื้นที่ว่างนอกข้อความและเป้าหมายการกด ลดขนาดหรือซ่อนบางตัวบนมือถือ ภาพตกแต่งควรใช้ alt ว่างและไม่รับ pointer events; หากเพิ่มการเคลื่อนไหวภายหลังให้รองรับ reduced motion

นี่คือชุดต้นแบบภาพนิ่ง ยังไม่ได้เชื่อมเข้าหน้าเว็บหรือ deploy การวางจริงและการเคลื่อนไหวเป็นขั้นตอนถัดไป
