# คำที่แสดงบนหน้าผู้บริหารมั่งมี

วันที่: 2026-10-01
สถานะ: มติ Owner ให้ตรวจคำทุกหน้า ให้อ่านเข้าใจโดยไม่ต้องรู้ศัพท์ระบบ แล้วนำ spec และต้นแบบเข้า main/develop; ยังไม่เริ่มระบบจริง

เอกสารนี้กำหนด **ข้อความที่ผู้ใช้เห็น** รวมชื่อเมนู หัวข้อ คำอธิบาย ตัวกรอง ปุ่ม ข้อความแจ้งเตือน ข้อความสำหรับโปรแกรมอ่านหน้าจอ และหัวตารางใน Excel ใช้ร่วมกับ [หน้าจอ](mangmee-executive-business-ui-spec-th.md), [การนำทาง](mangmee-executive-navigation-comparison-spec-th.md), [รายรับ](mangmee-executive-usage-pareto-spec-th.md) และ [Excel](mangmee-executive-excel-export-spec-th.md)

## หลักการ

- บอกสิ่งที่ผู้ใช้จะได้ดูหรือทำ เช่น “รายรับ”, “ส่งออก Excel”, “ดูรายชื่อลูกค้ากลุ่มนี้”
- เมนูไม่ใช้ชื่อวิธีคำนวณ เช่น 80/20, Pareto หรือ Top spender; ตัวเลข 20% และ 80% ยังแสดงได้ในคำอธิบายที่ระบุชัดว่าเป็นสัดส่วนของบริษัทหรือรายรับ
- เงินในรายงานหมายถึงเงินที่ลูกค้าจ่ายให้มั่งมี หักเงินที่คืนให้ลูกค้า; ระบุเมื่อยังไม่หักค่าธรรมเนียมหรือต้นทุน ไม่เรียกยอดรับว่า “กำไร”
- ใช้คำเดียวกันทั้งเมนู หัวหน้า ปุ่มกลับ ตัวกรอง หน้ารายละเอียด และหน้าส่งออก ข้อความยาวต้องตัดบรรทัดได้ในธีมเดิม
- ไม่ใช้ศัพท์ implementation หรือข้อความเรื่องการพัฒนาระบบในขั้นตอนของผู้ใช้ ข้อจำกัดตัวอย่างบอกตรง ๆ ว่าไม่มีข้อมูลจริงหรือยังไม่สร้างไฟล์จริง
- คงชื่อผลิตภัณฑ์ที่รู้จัก เช่น Excel, LINE, Facebook และชื่อแพ็กเกจ; identifiers ในสเปกทีมพัฒนา เช่น `pareto`, `TOP20`, `contactSource`, route/API และชื่อไฟล์คงเดิม ไม่เปลี่ยนสูตรหรือสิทธิ์จากการเปลี่ยนคำ

## คำที่ใช้ร่วมกัน

| ตำแหน่ง/คำเดิม | ข้อความที่ใช้ |
|---|---|
| รายรับและ 80/20 | รายรับ |
| ลูกค้ารายใหญ่ · 80/20 | ลูกค้าที่สร้างรายรับสูง |
| 80/20 · Top spender | รายรับมาจากลูกค้ากลุ่มใด |
| Top 20% | ลูกค้าที่จ่ายสูงสุด 20% แรก / กลุ่มที่จ่ายสูงสุด 20% แรก ตามประโยค |
| กลุ่มยอดจ่าย | กลุ่มลูกค้าตามยอดจ่าย |
| ฐาน Pareto | บริษัทที่นำมาคำนวณสัดส่วนรายรับ |
| น้ำหนักบวก | ยอดที่ใช้คำนวณสัดส่วน; อธิบายว่าเป็นยอดจ่ายหลังหักคืนเงินที่มากกว่า 0 |
| บริษัทจริง/บริษัทภายใน | บริษัทลูกค้า/บริษัทของมั่งมี |
| ใช้ฟีเจอร์ | ใช้ระบบ; แสดงการเข้าสู่ระบบแยกจากการใช้งานจริง |
| ใช้ AI / ต้นทุน AI-OCR | ใช้ผู้ช่วย / ต้นทุนผู้ช่วยและการอ่านใบเสร็จ |
| เครดิตยอดเปิดบริษัท | ยอดขายครั้งแรกของเซลล์ |
| เซลล์ที่ได้เครดิตยอดเปิด | เซลล์ที่ได้รับยอดขายครั้งแรก; คนละเรื่องกับเซลล์ผู้แนะนำ |
| ยอดเปิดครั้งแรก | ยอดชำระครั้งแรก |
| วันตัดข้อมูล | วันที่แสดงในรายงาน |
| ตัวชี้วัด / ส่วนต่าง A − B | รายการ / ต่างกัน (A ลบ B) |
| จุดเปอร์เซ็นต์ | จุด; อธิบายประกอบว่า 60% เทียบ 40% ต่างกัน 20 จุด ห้ามใช้เปอร์เซ็นต์การเติบโตแทน |
| Export Excel / Excel Dashboard | ส่งออก Excel / ไฟล์ Excel พร้อมสรุปและกราฟ |
| production snapshot | ข้อมูลสมมติสำหรับทดลองหน้าจอ (ในต้นแบบ); ระบบจริงแสดงเวลาของข้อมูล |
| ชุดข้อมูลหมดอายุ | ข้อมูลรายงานเก่าแล้ว กรุณาโหลดใหม่ก่อนสร้างไฟล์ |

## ขอบเขตตรวจ

ตรวจภาพรวม การใช้งาน/อันดับ รายรับทั้งสองมุม ลูกค้า/ธุรกิจ/ช่องทาง/เซลล์ เปรียบเทียบ รายชื่อบริษัท รายละเอียดบริษัท บัญชีผู้บริหาร/ฟอร์ม/สถานะ และทุกส่วนในตัวอย่างส่งออก รวมสถานะข้อมูลไม่พอ ไม่พบข้อมูล โหลดไม่สำเร็จ ไม่มีสิทธิ์ และตัวเลือกทดลองหน้าจอ

ข้อมูลติดต่อยังใช้บัญชีเจ้าของตาม Excel spec §9; ช่องทางและเซลล์ยังแยกกัน; สูตรรายรับ/คืนเงิน กลุ่มบริษัท การจัดอันดับ และตัวเลขตัวอย่างคงเดิม การลบข้อมูลยังซ่อนทุกทางเข้า

เกณฑ์ตรวจ: คำต้องตรงระหว่างหน้าจอและส่งออก ไม่มีศัพท์ต้องห้ามหลงเหลือในข้อความที่แสดง จำนวนบริษัท/ยอดเงิน/กลุ่มจากกราฟไม่เปลี่ยน ปุ่มและการค้นหายังใช้ได้ และไม่มีข้อความล้นจอบนมือถือ งาน API/ข้อมูลจริงยังไม่ผ่านการตรวจจากต้นแบบนี้
