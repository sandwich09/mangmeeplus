## 3. กติกา

### 3.1 ตัวแปลช่วงเวลา (deterministic, ใน `packages/contracts`)

เพิ่ม `periods: LineAiPeriodCandidate[]` ใน `LineAiValueCandidates` (additive; gateway เก่าไม่รู้จักและไม่พัง) คำนวณจากข้อความ + `todayIso` (วันปฏิทิน Asia/Bangkok) โดยโค้ดเท่านั้น:

```
LineAiPeriodCandidate = {
  span: string;                      // ข้อความต้นฉบับที่อ่านมา
  kind: 'day'|'week'|'month'|'quarter'|'year'|'range'|'last_n_days';
  fromDate: string; toDate: string;  // ISO ค.ศ. ทั้งคู่ inclusive
  monthKey?: string;                 // 'YYYY-MM' เมื่อ kind='month'
  source: 'relative'|'explicit'|'named_month';
  label: string;                     // ไทย เช่น "เดือนที่แล้ว (ส.ค. 2569)"
  assumptions: string[];             // เช่น 'week_monday_sunday', 'year_read_be', 'day_before_read_as_yesterday'
}
```

คำศัพท์ขั้นต่ำ (ไทย + อังกฤษ, ไม่สนช่องว่าง/ตัวสะกดย่อทั่วไป):

| กลุ่ม | ตัวอย่างที่ต้องอ่านได้ | ผล |
| --- | --- | --- |
| วัน | วันนี้/today; เมื่อวาน/เมื่อวานนี้/yesterday; **วันก่อน** (อ่านเป็นเมื่อวาน + assumption); เมื่อวานซืน/day before yesterday; N วันก่อน/N days ago | `day` |
| หลายวันล่าสุด | 3 วันที่ผ่านมา, 7 วันล่าสุด, last 7 days, 30 วันย้อนหลัง | `last_n_days` (สิ้นสุดวันนี้, N ≤ 366) |
| สัปดาห์ | สัปดาห์นี้/อาทิตย์นี้/วีคนี้/this week; สัปดาห์ที่แล้ว/อาทิตย์ที่แล้ว/สัปดาห์ก่อน/อาทิตย์ก่อน/last week; N สัปดาห์ที่แล้ว | `week` = จันทร์–อาทิตย์ (Bangkok) |
| เดือน | เดือนนี้/this month; เดือนที่แล้ว/เดือนก่อน/last month; N เดือนที่แล้ว (N ≤ 24); ชื่อเดือน (สิงหาคม, ส.ค., Aug, August) ± ปี (2568, 68, 2025, 25) — ไม่มีปี = เดือนนั้นครั้งล่าสุดที่ไม่อยู่ในอนาคต | `month` + `monthKey` |
| ไตรมาส | ไตรมาสนี้/ไตรมาสที่แล้ว/Q1–Q4/ไตรมาส 1–4 (± ปี) | `quarter` (ปฏิทิน) |
| ปี | ปีนี้/this year; ปีที่แล้ว/ปีก่อน/last year; ปี 2568 / 2025 | `year` (ปฏิทิน ไม่ใช่ปีบัญชี) |
| หน่วยปฏิทินล่าสุด | N เดือนย้อนหลัง/ที่ผ่านมา/ล่าสุด/หลังสุด/ก่อนหน้านี้, ย้อนหลัง N เดือน, last/past/previous N months; N สัปดาห์/อาทิตย์/วีค/ไตรมาส/ปี ที่ผ่านมา/ล่าสุด/ย้อนหลัง; ครึ่งปีที่ผ่านมา | N หน่วยเต็มก่อนหน่วยปัจจุบัน (§4.5); N = 1 ใช้ชนิดของหน่วย, หลายหน่วยใช้ `range` |
| เดือนถึงเดือน | สิงหา ถึง ตค, ตั้งแต่เดือนสิงหาคมถึงเดือนตุลาคม, เดือน 8–10, ระหว่าง ส.ค. กับ ต.ค. | `range` รวมทุกเดือนตรงกลาง; ไม่ออกปลายช่วงซ้ำ (§4.5) |
| ตั้งแต่ต้นงวดถึงวันนี้ | ตั้งแต่ต้นเดือน, ต้นเดือนนี้ถึงวันนี้, ตั้งแต่ต้นปี, year to date, ytd | เหมือนเดือนนี้/ปีนี้ |
| ช่วงตรง ๆ | 1–15 ก.ย., ตั้งแต่ 1 ถึง 15 กันยายน, 1/9–15/9/68, from 1 to 15 Sep | `range` (ใช้ date candidate เดิม 2 ตัวที่ไม่กำกวม) |

- ปี: ≥ 2400 = พ.ศ.; ปีสองหลักของช่วงอ่านข้อมูลเลือกศักราชเดียวที่ไม่เกินปีปัจจุบันและย้อนหลังไม่เกิน 15 ปี พร้อม marker ว่าแปลศักราชแล้ว; ถ้าไม่มีศักราชเข้าเกณฑ์ไม่ออกช่วง — ไม่เปลี่ยนกติกา `dates[]` สำหรับวันที่บันทึกรายการ (กำกวมต้องถาม)
- อนาคต (พรุ่งนี้, เดือนหน้า, ปีหน้า) **ไม่ออก candidate** สำหรับการอ่านข้อมูล (ไม่มีข้อมูล) — โมเดล/tool ใช้ default และคำตอบระบุช่วงที่ใช้; ไม่เดา
- คำที่ตีความไม่ได้ชัด (ต้นเดือน, ปลายเดือน, ช่วงนี้, เร็ว ๆ นี้) ไม่ออก candidate → default เดือนปัจจุบัน + คำตอบระบุช่วง
- หลาย candidate ในข้อความเดียว (เช่น "เมื่อวานกับเดือนที่แล้ว") ออกทั้งหมด โมเดลเลือก/แยกเรียกตามเดิม
- recall ชนะ precision (ADR 0011): candidate เกินไม่เป็นไร เพราะเป็นแค่ชุดที่อนุญาต ไม่ใช่คำตอบ

### 3.2 การใช้ candidate ในเส้นทางโมเดล (gateway)

- prompt ของ router/loop: ช่วงเวลาให้เลือกจาก `valueCandidates.periods` **เท่านั้น** (คัดลอก `fromDate/toDate/monthKey` ตรง ๆ) ห้ามคำนวณวันเอง; ถ้าผู้ใช้ไม่ระบุช่วง ห้ามใส่วันที่ (ให้ tool ใช้ default ของตัวเอง = เดือนปัจจุบัน)
- `allowedLoopDates`/`preparedAllowedDates` รวม `fromDate/toDate` ของทุก period candidate; sanitizer whitelist `periodKey` (ต้องเท่ากับ `monthKey` ของ candidate หรือเดือนปัจจุบัน), `newUntil` (ใหม่) และคงกติกา `date/fromDate/toDate` เดิม
- เลน deterministic: `fromDate/toDate/date/periodKey/newSince/newUntil` ที่ตรงกับ candidate หรือวันนี้/เดือนนี้ ผ่านได้ → คำถามที่มีช่วงสัมพัทธ์ตอบสำเร็จรูปได้ (ไม่ต้องถอยไปเส้นทางปกติ) แต่ห้ามลดการตรวจ security เดิม
- ทั้งสองเส้นทางต้องส่งช่วงเดียวกันให้ tool เมื่อข้อความเดียวกัน (พิสูจน์ด้วย test เทียบ input ของ tool)

### 3.4 คำตอบ

- ทุกคำตอบที่มีช่วงเวลาต้องระบุช่วงที่ใช้จริง (มีอยู่แล้วใน formatter/composer — ต้องคงและเพิ่ม test); ช่วงที่มาจากคำสัมพัทธ์ให้พิมพ์ทั้งคำและวันที่ เช่น "เดือนที่แล้ว (1–31 ส.ค. 2569)"
- ถ้าโมเดลใส่วันที่ที่ไม่มี candidate รองรับ → ถูกทิ้ง → tool ใช้ default และคำตอบยังระบุช่วง (ไม่เงียบ)
- telemetry ต่อ turn: `periodSource: 'explicit'|'relative'|'default'` (enum เท่านั้น) ในบรรทัด log ที่มีอยู่ของ prepared lane / loop

### 4.1 Incident amendment: สรุปค่าใช้จ่ายหลายเดือน (2026-09-25)

คำถาม LINE ที่ระบุ ก.ค. และ ส.ค. 2569 ได้ผลเพียง ก.ค. เพราะ `valueCandidates` หล่นระหว่าง AI Gateway กับ AgentCore และไม่มีการตรวจว่าผล tool ครบทุกเดือนก่อนตอบ ทั้งที่ยอด ก.ค. ตรงกับข้อมูล Production แล้ว กติกาเพิ่มเติม:

- ส่ง candidate ที่ตรวจรูปแบบและผูกกับข้อความเดิมผ่าน Gateway → AgentCore; payload เก่าที่ไม่มี candidate ยังอ่านได้
- รับคำสะกดเดือนกรกฎาคมแบบ `กรกฏาคม` ที่เกิดในคำถามจริง โดยไม่แก้ข้อความต้นฉบับ

### 4.2 ชื่อเดือนสะกดผิดในคำถาม LINE (2026-09-25)

- เมื่อชื่อเดือนเต็มภาษาไทยที่มีขอบคำชัดผิดหนึ่งอักขระ Unicode และชี้ไปยังเดือนเดียว ให้ตัวแปลช่วงเวลาแก้ความหมายโดยไม่แก้ข้อความต้นฉบับ พร้อมบันทึก assumption ว่ามีการแก้คำสะกด; ปีและช่วงวันที่ยังใช้กติกาเดิม

### 4.3 เลขเดือนและชื่อย่ออังกฤษ (2026-09-25)

- `เดือน 1`–`เดือน 12` และ `month 1`–`month 12` เป็นชื่อเดือนปฏิทิน; ระบุปีด้วย `ปี`/`year` หรือปีสี่หลักได้ หากไม่ระบุปีใช้เดือนนั้นครั้งล่าสุดที่ไม่อยู่ในอนาคตตาม §3.1
- รายการเลขเดือนที่มีคำนำหน้าเดียว เช่น `เดือน 1 2 3` หรือ `เดือน 1, 2 และ 3` ต้องได้ candidate ครบทุกเดือน เพื่อให้คำถามค่าใช้จ่ายหลายเดือนไม่ตอบเพียงเดือนแรก
- รายการ 1–12 ในข้อความเดียวต้องรักษา candidate ทั้ง 12 ช่วง; ถ้า tool-call budget ไม่พอให้ระบุเดือนที่ยังดึงไม่ครบตามกติกา §4.1
- ชื่อและชื่อย่ออังกฤษ Jan–Dec ใช้กติกาเดิมทั้ง 12 เดือน; `may` ที่ไม่มีปีต้องมี `เดือน` หรือ `month` กำกับ เพราะเป็นคำกริยาอังกฤษได้ด้วย
- เลขเดือนนอก 1–12 ต้องถามให้ระบุใหม่ก่อนเรียก tool; เลขเดือนที่ระบุปีอนาคตยังไม่มี candidate ให้อ่านและต้องขอให้ตรวจเดือน/ปี ไม่ถอยไปใช้เดือนปัจจุบัน

Acceptance: ตรวจเดือนเลข 1–12 และชื่อย่ออังกฤษทั้ง 12 แบบเป็น `monthKey` ที่ถูกต้อง; `เดือน 1 2 3` ได้ 3 เดือน; `เดือน 13` ไม่มีการอ่านข้อมูลและถามยืนยันเดือน.

### 4.4 ชื่อเดือน/ไตรมาสที่ไม่ระบุปีแล้วถอยไปปีที่แล้ว (owner 2026-09-29)

### 4.5 คำบอกช่วงเวลาที่คนพูดจริง (owner 2026-10-05)

- **R1** `N เดือนย้อนหลัง/ที่ผ่านมา/ล่าสุด/หลัง/หลังสุด/ก่อนหน้า/ก่อนหน้านี้`, `ย้อนหลัง N เดือน`, `last/past/previous N months` ใช้ N เดือนปฏิทินเต็มก่อนเดือนปัจจุบัน; เช่น 5 ต.ค. 2569 และ N = 3 ได้ 1 ก.ค.–30 ก.ย. 2569 ไม่รวมตุลาคมที่ยังไม่เต็มเดือน พร้อม assumption `complete_units_exclude_current`; สัปดาห์/อาทิตย์/วีคใช้จันทร์–อาทิตย์เต็ม ไตรมาสและปีใช้หน่วยปฏิทินเต็มเช่นกัน (N = 1–24); ไม่มีจำนวนถือเป็นหนึ่งหน่วย, ครึ่งปีที่ผ่านมา/ย้อนหลัง/ล่าสุดคือ 6 เดือนเต็ม; วันล่าสุดยังนับรวมวันนี้ และ N เดือนที่แล้ว/ก่อนยังเป็นเดือนเดียวเมื่อ N เดือนก่อน
- **R2** จำนวนรับเลขไทย/อารบิกและคำจำนวนไทยอย่างน้อยหนึ่ง–สิบสอง ใช้กติกาเดียวกันทุกหน่วย; คำประมาณจำนวน เช่น `สองสามเดือน` หรือ `สองสามเดือนนี้` ไม่ออกช่วงและไม่อ่านเพียงส่วนท้าย
- **R3** ช่วงชื่อเดือนรับชื่อเต็ม ชื่อพูด คำย่อไทยมี/ไม่มีจุด ชื่ออังกฤษ และเลขหลัง `เดือน` ทั้งสองฝั่ง; เชื่อมด้วย `ถึง`, `จนถึง`, `ยัน`, `-`, `–`, `—`, `~`, `to`, `until`, `through` และ `ระหว่าง X กับ/และ/ถึง Y`; รับ `ตั้งแต่/จาก/ช่วง` และคำติดกัน เช่น `ตั้งแต่สิงหาถึงตุลา`; ช่วงกินข้อความทั้งสองปลาย ออกหนึ่งช่วงรวมทุกเดือนตรงกลาง ส่วนรายการและการเทียบเดือนยังแยกตามเดิม
- ปีไม่ระบุ: เริ่มจากเดือนเริ่มครั้งล่าสุดที่ไม่ใช่อนาคต แล้วจบที่เดือนปลายครั้งแรกตั้งแต่เดือนเริ่ม; ระบุปีท้ายอย่างเดียวคือปีของเดือนปลาย แล้วหาเดือนเริ่มครั้งล่าสุดไม่เกินปลาย; ระบุปีต้นอย่างเดียวให้ปลายเป็นครั้งแรกตั้งแต่ต้น; ระบุทั้งสองตามนั้น ถ้ากลับลำดับหรือเกิน 24 เดือน ไม่รวมเป็นช่วงและคงเดือนแยกเดิม; เริ่มในอนาคตไม่ออกช่วง ปลายเกินวันนี้ตัดถึงวันนี้พร้อม marker เดิม
- helper `calendarMonthsForPeriod(period, todayIso)` คืนเดือนเรียงจากเก่าไปใหม่พร้อม `monthKey/fromDate/toDate/label` โดยใช้คำแสดงวันที่ไทยชุดเดิม เฉพาะเริ่มวันที่ 1 และจบวันสุดท้ายของเดือน หรือจบวันนี้พร้อม marker ที่ตัดถึงวันนี้; นอกนั้นคืน `null` ยังไม่มี consumer ในรอบนี้
- **R4** ไม่ระบุปีใช้ `year_assumed_latest_past` ตามเดิม ไม่ถามปี; ปีที่ระบุต้องใช้ตามผู้ใช้ ปีสองหลักสำหรับอ่านช่วงใช้ศักราชที่เข้าเกณฑ์ 15 ปีเพียงค่าเดียว (`ปี 69` = 2569, `ปี 25` = 2025, `ปี 99` ไม่มีค่าเข้าเกณฑ์) พร้อม marker ที่แปลศักราช ไม่ใช้กติกานี้เปลี่ยนวันที่บันทึกรายการ
- **R5** `เดือนย้อนหลัง/ล่าสุด/ที่ผ่านมา`, `เดือนไหน`, `ทุกเดือน`, `เฉลี่ยต่อเดือน`, `เดือนหนึ่งจ่ายประมาณเท่าไหร่`, `เดือนเดียวกันปีที่แล้ว`, `แต่ละเดือน`, `รายเดือน`, `เดือนละเท่าไหร่` ไม่ใช่ชื่อเดือนสะกดผิด; `เดือนกรกดาคน และ สิงหาคม` และ `เดือน 13` ยังต้องถามตาม §4.2
- **R6** ช่วงยาวมีสิทธิ์ก่อนคำย่อย: `ขอดูยอดแยกเดือน 3 เดือนล่าสุด` คือ ก.ค.–ก.ย.; `วันที่ 1 ถึง 15 เดือนที่แล้ว` คือ 1–15 ก.ย.; `วันที่ 1-5`/`วันที่ 1 ถึง 5` ใช้เดือนนี้; ชื่อเดือนตามด้วยปีนี้/ปีที่แล้ว/ปีก่อนเป็นเดือนเดียวตามปีนั้น และชื่อพูดตามด้วยที่ผ่านมาใช้ครั้งล่าสุดที่ไม่ใช่อนาคต; `ตั้งแต่ต้นเดือน`, `ต้นเดือนนี้ถึงวันนี้`, `ตั้งแต่ต้นเดือนถึงตอนนี้` เท่ากับเดือนนี้ และ `ตั้งแต่ต้นปี`, `ต้นปีถึงปัจจุบัน`, `ตั้งแต่ต้นปีถึงตอนนี้`, `year to date`, `ytd` เท่ากับปีนี้

Acceptance: ตาราง R1–R6 ใน `line-ai-value-normalizer.spec.ts` รวมขอบเดือน/ปี/ปีอธิกสุรทิน ช่วงข้ามปี ตัวเลขและคำจำนวน; ทุก 186 วลีจาก matrix ของ controller ตรวจ span ต้นฉบับ เพดาน candidate ไม่เริ่มอนาคต และ wire V1/V2 รับได้เหมือนเดิม; ไม่รันโมเดลและยังไม่ยืนยันคำตอบจริงบน LINE

### 4.5.0 คำย่อเดือนที่พิมพ์จุดท้ายอย่างเดียว (owner บน LINE UAT 2026-10-05 17:49)

`เทียบค่าใช้จ่าย กค. สค. กย.` ถูกถามกลับว่าหมายถึงช่วงใด เพราะตัวแปลรู้จัก `ก.ค.` และ `กค` แต่ไม่รู้จัก `กค.` (ไม่มีจุดกลาง มีจุดท้าย) ซึ่งเป็นวิธีพิมพ์ปกติบนมือถือ กติกา: คำย่อไทยไม่มีจุด 12 คำรับจุดท้ายได้ทุกที่ที่รับคำย่อ (เดือนเดี่ยว รายการหลายเดือน ช่วงเดือน ช่วงวัน `ตั้งแต่…` และเดือน+ปีสัมพัทธ์) ขอบคำเดิมยังบังคับ (`มีค่าใช้จ่าย`, `ร้านกค. จำกัด`, `สค.บ.` ไม่ใช่เดือน) และเพิ่มขอบท้าย `กับ`, `ค่ะ/คะ/ครับ/นะ/ล่ะ/ละ`, `!`/`?` กับขอบหน้า `กับ` ให้คำย่อไม่มีจุดกลาง รอบ P2 เคยจัด `กย.` ไว้นอกขอบเขต: เป็นการตัดสินใจที่ผิดของ controller และแก้ในรอบนี้

### 4.5.0.1 รูปแบบการพิมพ์เดือนและปีในกลุ่มเดียวกัน (controller 2026-10-05 หลังกรณี `กค. สค. กย.`)

ไล่วิธีพิมพ์เดือน/ปีในคำถามเปรียบเทียบอีก 45 แบบ แล้วแก้ทุกแบบที่อ่านไม่ได้หรืออ่านผิด:

- ชื่อเดือนแบบพูดในคำเปรียบเทียบ: `เทียบสิงหากับกันยา`, `เทียบกรกฎากับสิงหา`, `สรุปกันยา` (เดิมไม่มี candidate จึงถามกลับ) รับ `เทียบ`/`สรุป` นำหน้า และ `กับ`/`เทียบ` ตามหลัง; `กับ` นำหน้าชื่อเดือนแบบพูดรับเฉพาะเมื่อมีชื่อเดือนอยู่ก่อน `กับ` เท่านั้น — `จ่ายให้กับกันยา 500 บาท` และ `ไปกับตุลา` ยังเป็นชื่อคน
- เดือนสามเดือนขึ้นไปที่คั่นด้วยขีดคือรายการ ไม่ใช่ช่วง: `ก.ค.-ส.ค.-ก.ย.` (เดิมอ่านเป็นช่วง ก.ค.–ส.ค. กับ ก.ย.), `กค-สค-กย`; สองเดือนยังเป็นช่วงเดียว
- คำย่อไม่มีจุดกลางติดกับคำก่อนหน้า: `ค่าใช้จ่ายกค.`, `ยอดกย.`, `สรุปกย.`, `รายจ่ายสค` (เดิมไม่มี candidate จึงใช้เดือนปัจจุบันแทนเดือนที่ถาม) และตามด้วย `เทียบ`, `นี้`, `-`, `/`; ขอบท้ายยังกันคำอื่น (`ของมีค่า`, `ของพยาบาล`, `สคริปต์`)
- ปีที่ระบุศักราช: `พ.ศ. 2568`, `ปี ค.ศ. 2025`; `ทั้งปี` ที่ไม่บอกปี = ปีนี้ (ถ้ามีปีอยู่ข้างหน้าหรือข้างหลัง ใช้ปีนั้น); ไตรมาสที่นับเป็นคำ: `ไตรมาสสาม`, `ไตรมาสแรก`
- ยังไม่อ่าน (ตั้งใจ): `ครึ่งปีแรก/หลัง`, ปีสี่หลักโดด ๆ (`2568`), ตัวเลขเดือนโดด ๆ (`เทียบ 7 8 9`), วันในสัปดาห์

### 4.5.3 ช่วงที่เขียนวันเริ่มและวันสิ้นสุด (P2, owner 2026-10-05)

- ขอบเขตมีเพียงสามรูปแบบ: วัน–เดือนถึงวัน–เดือน, วันที่ถึงวันนี้/ตอนนี้/ปัจจุบัน และวันที่ตัวเลขเต็มสองฝั่ง; ครึ่งปี ช่วงเดียวกันปีก่อน `กย.` `9/2569` ชื่อวันในสัปดาห์และคำกำกวมยังไม่ทำตาม owner
- `D ชื่อเดือน [ปี] ถึง D ชื่อเดือน [ปี]` ออกหนึ่ง `range` ครอบข้อความทั้งสองปลาย ไม่ออกเดือนปลายซ้ำ; รับชื่อเดือนและตัวเชื่อมชุดเดียวกับช่วงเดือน P1, `วันที่` ก่อนวันทั้งสองฝั่ง, คำนำหน้าเดิม และข้อความติดกัน เช่น `ตั้งแต่1ส.ค.ถึง31ต.ค.`
- ปีไม่ระบุ: วันเริ่มเป็นครั้งล่าสุดที่ไม่เกินวันนี้ แล้ววันสิ้นสุดเป็นครั้งแรกตั้งแต่วันเริ่ม; ระบุปีท้ายอย่างเดียวคือปีของวันสิ้นสุด, ปีต้นอย่างเดียวให้วันสิ้นสุดเป็นครั้งแรกตั้งแต่วันเริ่ม, ระบุทั้งสองตามนั้น; ถ้าสิ้นสุดก่อนเริ่มหรือวันไม่มีจริงไม่รวมเป็นช่วง และคงการอ่านเดือนเดิม; เริ่มในอนาคตไม่ออกช่วง ปลายอนาคตตัดถึงวันนี้พร้อม marker เดิม
- `D ชื่อเดือน [ปี] ถึง/จนถึง/ยัน วันนี้/ตอนนี้/ปัจจุบัน` และ `to today`/`until now` เป็นช่วงจากวันนั้นถึงวันนี้; ปีไม่ระบุใช้วันนั้นครั้งล่าสุดที่ไม่ใช่อนาคต; `ตั้งแต่ 15 ก.ย.` ที่ไม่มีปลายช่วงยังได้เดือนกันยายนทั้งเดือนตามเดิม ไม่เพิ่มความหมายว่าถึงวันนี้
- `ตั้งแต่`/`นับจาก`/`since` + วันที่แบบมีชื่อเดือน หรือ + ชื่อเดือน โดยไม่มีปลายช่วง = จากวันนั้น (หรือวันที่ 1 ของเดือนนั้น) ถึงวันนี้; กติกานี้อยู่หลังกติกาช่วงทุกแบบ ช่วงที่บอกปลายจึงอ่านเหมือนเดิม และอยู่ก่อนกติกาเดือนเดี่ยว; วันที่ที่ไม่มีจริง เดือนที่ยังมาไม่ถึง คำที่แค่ขึ้นต้นคล้ายเดือน (`ตั้งแต่มีค่าใช้จ่าย`) และ `since may` ไม่เข้ากติกานี้; `ตั้งแต่เดือนที่แล้ว` ยังเป็นเดือนที่แล้วทั้งเดือน (ไม่ได้ทำ)
- วันที่ตัวเลขเต็ม `D/M/Y` ทั้งสองฝั่งรับ `/`, `-`, `.`, ปีสอง/สี่หลัก และเลขไทย; ศักราชปีสองหลักใช้ P1 R4 เฉพาะช่วงอ่านข้อมูล ส่วนลำดับวัน/เดือนใช้ `numericDayRange` เดิม: ค่าส่วนแรกเกิน 12 ล็อกวัน/เดือนทั้งช่วง, ค่าส่วนที่สองเกิน 12 ล็อกเดือน/วันทั้งช่วง, ถ้าขัดกันไม่ออกช่วง และถ้าไม่มีฝั่งใดล็อกให้ใช้วัน/เดือนพร้อม `order_assumed_day_month`; เช่น `1/2/69 ถึง 3/4/69` = 1 ก.พ.–3 เม.ย. 2569 พร้อม marker ว่าแปลศักราชแล้ว แต่ `dates[]` ยังคงกำกวมตามกติกาบันทึกรายการ
