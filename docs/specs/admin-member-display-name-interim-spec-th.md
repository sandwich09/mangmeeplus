# เพิ่มช่องแก้ชื่อ Owner ใน Admin Console

สถานะ: Implemented และตรวจเฉพาะจุดผ่าน (2026-09-28); ผลตรวจและข้อจำกัดอยู่ใน memory

ปัญหา: Owner ไม่มีช่องเปลี่ยนชื่อบัญชี เช่น `MangmeePlus.Test`

## สิ่งที่จะเพิ่ม

- ที่ **บริษัท → สมาชิก → แถว Owner → แก้ไขชื่อที่แสดง** มีช่องชื่อเดิมให้แก้ และปุ่มบันทึก/ยกเลิก ใช้รูปแบบฟอร์มเดิม ไม่ต้องกรอกเหตุผลหรือยืนยันซ้ำ
- บันทึก `User.displayName` ด้วย userId ใช้ได้แม้ไม่มีข้อมูลพนักงานหรือรหัสผ่าน
- ใช้สิทธิ์ `system.partner_member.manage` เดิม ตรวจว่าเป็น Owner ของบริษัทที่เลือกและไม่ใช่บัญชี platform/protected ก่อนเขียน
- ตัดช่องว่างหัวท้าย รับชื่อ 1–160 ตัวอักษรตาม `.length`; ไม่รับชื่อว่างหรือ control characters ตรวจฝั่ง API ด้วย
- ส่งชื่อใหม่พร้อมชื่อเดิม (`expectedDisplayName`) และเขียนเมื่อชื่อเดิมยังตรงกัน หากมีคนแก้ไปแล้วให้โหลดใหม่ ไม่ต้องเพิ่ม revision field หรือตาราง
- บันทึกชื่อและ audit ใน transaction เดียว ใช้รูปแบบ audit เดิม ระบุผู้แก้/บัญชีเป้าหมายโดยไม่บันทึกค่าชื่อใน log
- ระหว่างบันทึกกันกดซ้ำ; ผิดพลาดแจ้งในฟอร์มและเก็บชื่อที่พิมพ์ไว้ สำเร็จอัปเดตชื่อใน Console และแจ้งให้ Owner รีเฟรชหน้า

## ผลกระทบ

ชื่อนี้ใช้ร่วมทุกบริษัทของบัญชีเดียวกัน ต้องมีข้อความบอกข้างช่องกรอก เปลี่ยนเฉพาะชื่อบัญชี ไม่แตะชื่อร้าน ชื่อพนักงาน บทบาท สิทธิ์ รหัสผ่าน หรือ LINE

งานนี้ไม่เพิ่มหน้าแก้เองฝั่ง Owner ไม่เพิ่ม migration/dependency และไม่รวมการแก้บั๊กชื่อพนักงาน/ตัวแสดงชื่อเดิม ข้อจำกัดที่พบเก็บไว้ใน [memory](../agent-memory/admin-member-display-name-interim.md)

## ตรวจรับ

- [x] Console แก้ชื่อ Owner ที่ไม่มี EmployeeAccessProfile และอ่านชื่อกลับหลัง reload ได้ (browser fixture); เมนูบัญชีใช้ User.displayName เดิม ยังไม่ได้ทดสอบกับบัญชีจริง
- [x] ผู้ไม่มีสิทธิ์, สมาชิกผิดบริษัท, target ที่ไม่ใช่ Owner/platform-protected, ชื่อว่าง/ยาวเกิน และชื่อเดิมไม่ตรง ต้องเขียนไม่ได้
- [x] บทบาทและข้อมูลอื่นคงเดิม; มี audit เมื่อเปลี่ยนชื่อ; ยกเลิกหรือบันทึกล้มเหลวไม่เปลี่ยนข้อมูล
