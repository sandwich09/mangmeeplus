# ลิงก์เดโม่สำหรับลูกค้า (Sales demo link) — Spec

สร้าง 2026-11-06 | เจ้าของ: Owner | สถานะ: owner ให้ทำต่อ 2026-11-06 บนระบบจริง ไม่เพิ่มเครื่องใหม่

## 1. เป้าหมาย

ทีมขายส่งลิงก์เดียวให้ลูกค้าทาง LINE หรือ Facebook ลูกค้ากดแล้วเห็นระบบมั่งมีที่หน้าตาเหมือนระบบจริง
พร้อมแชท LINE จำลองอยู่ข้าง ๆ ได้ลองกดเองโดยไม่ต้องสมัครและไม่ต้องล็อกอิน

คำสั่ง owner (2026-11-06): "ตอบตามบท ให้เป็นลิงค์ ทั้งระบบแยก ไม่ต้อง login ลิ้งค์มีอายุ 3 วัน
หน้าตาเหมือนระบบจริง และมีแชทไลน์ได้ข้างบอกเป็นระบบจำลอง"

## 2. ผู้ใช้และเส้นทางหลัก

1. เซลล์เปิดคอนโซลขายบนระบบจริง แล้วกด **สร้างลิงก์เดโม่** ได้ลิงก์ `https://mangmeeplus.com/d/<token>`
   พร้อมวันหมดอายุ (ตอนนี้ + 3 วัน) และปุ่มคัดลอก
2. ลูกค้ากดลิงก์ ระบบเดโม่สร้างร้านอาหารตัวอย่างชุดใหม่ให้ลิงก์นั้น แล้วพาเข้าหน้าภาพรวมร้านทันทีโดยไม่ต้องล็อกอิน
3. ลูกค้ากดดูเมนูต่าง ๆ ได้เหมือนเจ้าของร้านจริง เช่น รายจ่าย เบิกเงิน อนุมัติ 50 ทวิ พนักงานและสิทธิ์
4. ข้างจอมีแชท LINE จำลอง (มือถือเป็นปุ่มลอย กดแล้วเปิดแชทเต็มจอ) ลูกค้ากดปุ่มคำถามที่เตรียมไว้
   มั่งมีตอบตามบท ข้อความ และการ์ดหน้าตาเหมือน LINE จริง
5. กดลิงก์ซ้ำภายใน 3 วัน ได้ร้านเดิมที่ตัวเองกดค้างไว้ หลัง 3 วันขึ้นหน้า "ลิงก์นี้หมดอายุแล้ว" พร้อมปุ่มคุยกับทีมดูแล

## 3. กติกา

- **แยกจากร้านจริงทั้งหมด (owner 2026-11-06: ไม่เอาเครื่องใหม่):** เดโม่รันบนระบบจริง แต่ทุกลิงก์ได้ร้านสำเนา
  `reportClassification = 'DEMO'` ที่แยกด้วยขอบเขตร้าน (tenant) แบบเดียวกับร้านลูกค้า ร้าน DEMO มองไม่เห็นร้านอื่น
  และร้านอื่นมองไม่เห็นร้าน DEMO
- **ร้าน DEMO ทำของที่มีค่าใช้จ่ายหรือส่งออกนอกระบบไม่ได้ (ตรวจที่ฝั่ง API):** เรียก AI อ่านเอกสารหรือแชท AI,
  ซื้อหรือเปลี่ยนแพ็กเกจ, ส่งอีเมล, ส่ง LINE, ผูก LINE, เชิญพนักงาน และเปลี่ยนรหัสผ่าน ผู้ใช้ของร้าน DEMO
  ไม่มีอีเมล ไม่มีเบอร์โทร และไม่มี LINE จึงไม่มีช่องทางส่งออกตั้งแต่แรก ส่วนการตรวจที่ API คือกำแพงชั้นที่สอง
- **ลิงก์ละหนึ่งร้าน:** แต่ละลิงก์ได้สำเนาร้านตัวอย่างของตัวเอง ลูกค้าคนหนึ่งกดอนุมัติแล้วไม่ไปเปลี่ยนจอของลูกค้าอีกคน
- **อายุ 3 วัน:** นับจากเวลาที่เซลล์สร้างลิงก์ ไม่ใช่เวลาที่ลูกค้ากดครั้งแรก การเข้าระบบหมดพร้อมลิงก์
  พอหมดอายุ ร้านสำเนาถูกปิดทันที แล้วงานตรวจอายุแพ็กเกจรอบถัดไป (ทุกประมาณ 5 นาที) ลบข้อมูลทั้งร้าน ไฟล์ที่อัปโหลด และผู้ใช้ของร้าน (เจ้าของสั่ง 2026-11-06) แถวลิงก์ยังเก็บไว้เป็นประวัติของเซลล์
- **บอกตลอดว่าเป็นระบบจำลอง:** แถบบนสุดทุกหน้าเขียนว่า "ระบบจำลอง ข้อมูลเป็นตัวอย่าง" และหัวแชทเขียนว่า "แชทจำลอง"
- **แชท:** ดูข้อ 5.1 (AI ตอบจริงภายในเครดิตของลิงก์)
- **การกระทำที่ต้องใช้ของจริง** (อัปโหลดใบเสร็จให้ AI อ่าน, ซื้อแพ็กเกจ, ส่งอีเมล, ผูก LINE)
  ขึ้นข้อความประโยคเดียวว่าในระบบจำลองทำไม่ได้ และชี้ทางไปต่อ: ลองดูในแชท หรือสมัครใช้จริงฟรี
- **ไม่มีสวิตช์:** ระบบรู้ว่าเป็นเดโม่จากข้อมูลร้าน (`reportClassification = 'DEMO'`) ไม่ใช่จาก env flag

## 4. ร้านตัวอย่าง

ร้านอาหาร "ครัวมั่งมี (ร้านตัวอย่าง)" แพ็กเกจ 1999 เปิดทุกเมนูที่ขาย พนักงาน 4 คน
(เจ้าของ ผู้จัดการ การเงิน พนักงาน) ข้อมูลย้อนหลัง 3 เดือนที่นับวันจากวันที่สร้างสำเนา ประกอบด้วย:

- รายจ่ายจากใบเสร็จประมาณ 30 รายการ หลายหมวด (วัตถุดิบ ค่าน้ำไฟ ค่าแก๊ส ค่าเช่า) มีทั้งรอตรวจและบันทึกแล้ว
- คำขอเบิกเงิน 3 รายการ: รออนุมัติ, อนุมัติรอจ่าย, จ่ายแล้ว
- หนังสือรับรองหัก ณ ที่จ่าย (50 ทวิ) 1 ฉบับ
- คู่ค้า 5 ราย

ลูกค้าดูชื่อเจ้าของร้านเป็น "คุณมั่งมี (ตัวอย่าง)" ข้อมูลทุกชิ้นเป็นของสมมติ

## 5. บทแชท LINE จำลอง

ปุ่มคำถามเริ่มต้น และสิ่งที่มั่งมีตอบ:

| ปุ่ม | มั่งมีตอบ |
| --- | --- |
| ส่งรูปใบเสร็จ | แสดงรูปใบเสร็จตัวอย่าง → "กำลังอ่าน…" → การ์ดสรุปใบเสร็จ (ร้าน วันที่ ยอด หมวด) + ปุ่ม "ดูในระบบ" ที่เปิดรายการนั้นในจอข้าง ๆ |
| เดือนนี้จ่ายไปเท่าไหร่ | การ์ดยอดรายจ่ายเดือนนี้แยกหมวด (ตัวเลขตรงกับหน้าภาพรวมของร้านสำเนา) |
| ขอเบิกค่าน้ำมัน 500 บาท | การ์ดคำขอเบิกรออนุมัติ + ข้อความว่าแจ้งผู้อนุมัติแล้ว |
| มีอะไรรออนุมัติบ้าง | การ์ดรายการรออนุมัติ + ปุ่ม "ไปอนุมัติ" ที่เปิดหน้าอนุมัติในจอข้าง ๆ |
| ออก 50 ทวิ ให้ช่างแอร์ | การ์ดยืนยันข้อมูล 50 ทวิ + ปุ่ม "ดูเอกสาร" |

ทุกคำตอบเขียนด้วยคำง่ายตามแนวของระบบจริง ตัวเลขในการ์ดอ่านจากร้านสำเนาของลิงก์นั้น จึงตรงกับจอเสมอ
บทเริ่มใหม่ได้ด้วยปุ่ม "เริ่มคุยใหม่"

## 5.1 แชทตอบด้วย AI จริง (owner 2026-11-06 แทนบทในข้อ 5)

คำสั่ง owner: "AI ไลน์ตอบจริงได้เลยนะ แต่เรากำหนดได้ว่าเครดิต ลิงค์นี้ได้เท่าไหร่ให้ default 80 และ อัพโหลดรูปได้ 3 รูปเหมือนเดิม
ของไลน์ก็มีปุ่มอัพโหลด pdf+รูปด้วย"

- แชทในหน้าต่างเด้งส่งข้อความเข้า **สมองเดียวกับ LINE AI จริง** และได้คำตอบกับการ์ดแบบเดียวกับ LINE แต่ไม่ส่งอะไรไปที่ LINE เลย
  คำตอบเก็บไว้ให้หน้าเว็บดึงไปแสดง
- ปุ่มคำถามลัดในข้อ 5 ยังอยู่ แต่กดแล้วส่งเป็นข้อความจริงให้ AI ตอบ และลูกค้าพิมพ์ถามเองได้
- มีปุ่มแนบไฟล์ รับรูปและ PDF
- **เครดิต AI ต่อหนึ่งลิงก์:** เซลล์กำหนดได้ตอนสร้างลิงก์ ค่าเริ่มต้น 80 (สูงสุด 300) ใช้สมุดเครดิต AI ที่มีอยู่ เครดิตหมดแล้วแชทบอกประโยคเดียวว่าเครดิตทดลองหมดแล้ว และชี้ทางเปิดร้านจริงฟรี
- **อ่านใบเสร็จหรือเอกสารได้ 3 ใบต่อลิงก์** เหมือนสิทธิ์ส่งฟรี ใช้ได้ทั้งจากแชทและจากหน้าอัปโหลดในเว็บ ใบที่ 4 แจ้งประโยคเดียวว่าครบ 3 ใบแล้ว
- กำแพงร้าน DEMO ยังห้ามซื้อแพ็กเกจ อีเมล ส่ง LINE จริง ผูก LINE เชิญพนักงาน และเปลี่ยนรหัสผ่านเหมือนเดิม
  ส่วน AI แชทและอ่านเอกสาร เปิดให้ภายในเครดิตและโควตา 3 ใบ

## 6. หน้าตา

- แชทเป็น **หน้าต่างเล็กเด้งขึ้น (mini pop-up) แบบแชทของ Facebook** (owner 2026-11-06): ปุ่มกลมสีเขียว LINE มุมขวาล่าง "แชท LINE (จำลอง)"
- จอกว้าง: กดแล้วเปิดหน้าต่างเล็กประมาณ 360 × 540 px ชิดขวาล่าง หน้าระบบด้านหลังยังกดใช้ได้ ย่อเก็บแล้วบทสนทนายังอยู่
- มือถือ (ออกแบบที่ 390 px ก่อน): กดแล้วเด้งขึ้นเกือบเต็มจอ มีปุ่มย่อ กดปุ่มในการ์ดแล้วย่อเก็บให้เห็นหน้าที่เปิด
- แชทใช้สีและรูปแบบฟองข้อความแบบ LINE (พื้นหลังฟ้าเทา ฟองขาวของมั่งมี ฟองเขียวของลูกค้า) และการ์ดแบบเดียวกับการ์ด System OA ที่ล็อกไว้

## 7. ความปลอดภัย

- ลิงก์เก็บเป็นแถวในฐานข้อมูล (เก็บแค่ hash ของโทเค็น เหมือนโทเค็นส่งต่อจาก LINE) พร้อมวันหมดอายุ ผู้สร้าง
  และร้านสำเนาที่ผูกไว้ โทเค็นสุ่ม 24 ไบต์ เดาไม่ได้ และยกเลิกลิงก์ได้
- เฉพาะสิทธิ์เซลล์และแอดมินระบบเท่านั้นที่สร้างลิงก์ได้ และบันทึกประวัติทุกครั้ง (ใคร สร้างเมื่อไหร่ หมดเมื่อไหร่)
- การเข้าระบบเดโม่ใช้ทางเดียวกับการส่งต่อจาก LINE ที่มีอยู่แล้ว (handoff token → session) จำกัดให้ใช้ได้เฉพาะร้านสำเนาของลิงก์นั้น
- จำกัดจำนวนร้านสำเนาที่สร้างได้ต่อชั่วโมง กันคนยิงลิงก์ปลอมหรือลิงก์เดิมรัว ๆ

## 8. เกณฑ์ผ่าน

1. เซลล์สร้างลิงก์ได้ และเห็นวันหมดอายุ
2. เปิดลิงก์ในมือถือที่ไม่เคยล็อกอิน แล้วเข้าหน้าภาพรวมร้านตัวอย่างได้ภายในไม่กี่วินาที
3. ทุกเมนูที่ขายเปิดได้ มีข้อมูลตัวอย่าง และมีแถบ "ระบบจำลอง"
4. กดทุกปุ่มในแชทได้คำตอบตามบท ตัวเลขตรงกับจอ ปุ่ม "ดูในระบบ" เปิดหน้าที่ถูกต้อง
5. ลิงก์ที่หมดอายุหรือถูกแก้ไขขึ้นหน้าหมดอายุ และไม่สร้างร้าน
6. ลิงก์สองอันได้ร้านคนละร้าน อนุมัติในร้านหนึ่งไม่กระทบอีกร้าน
7. ร้าน DEMO เรียก AI, ซื้อแพ็กเกจ, ส่งอีเมล หรือส่ง LINE ไม่ได้ (ทดสอบที่ API) และไม่ถูกนับในรายงานผู้บริหาร
8. ตรวจที่ 390 px และ 1556 px แล้วใช้งานได้
