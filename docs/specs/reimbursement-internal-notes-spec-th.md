# โน้ตภายในรายการเบิก

วันที่: 25 กันยายน 2569

## เป้าหมาย

ผู้ที่เปิดรายละเอียดใบเบิกในบริษัทได้ สามารถฝากข้อความประกอบการทำงานหลายรายการต่อใบเบิก และกลับมาแก้ไขหรือลบโน้ตได้ภายหลัง โดยไม่เปลี่ยนสถานะ จำนวนเงิน การอนุมัติ หรือเอกสารใบเบิก

## กติกา

- โน้ตเป็นข้อความภายในของใบเบิกหนึ่งใบ แสดงบนหน้ารายละเอียดใบเบิกตามเวลา พร้อมชื่อผู้เขียนและเวลาแก้ไข
- ผู้มีสิทธิ์อ่านใบเบิกตามกฎบริษัทและสาขาเดิมเท่านั้นที่อ่านและเพิ่มโน้ตได้ รวมถึงผู้รับมอบหมายอนุมัติใบนี้โดยเฉพาะ
- เพิ่มโน้ตได้ทุกสถานะของใบเบิก รวมถึงรายการที่จ่ายสำเร็จหรือปิดแล้ว โดยไม่เปลี่ยนสถานะหรือยอดเงิน
- ผู้เขียนแก้ไขและลบโน้ตของตนเองได้ เจ้าของบริษัทที่อ่านใบนี้ได้จัดการโน้ตอื่นได้
- รับข้อความ 1–2,000 ตัวอักษรหลังตัดช่องว่างหัวท้าย ห้ามข้อความว่าง; ลบเป็นการลบรายการนั้นออกจากหน้าจอ
- เก็บ audit ของการเพิ่ม แก้ไข และลบ พร้อมผู้กระทำและรหัสโน้ต โดยไม่คัดลอกเนื้อหาเข้า audit
- โน้ตไม่อยู่ในรายการเบิกแบบสรุป, ใบเบิกพิมพ์, หลักฐานส่งออก, LINE, AI, หรือข้อความแจ้งเตือน

## เกณฑ์รับงาน

- เพิ่มโน้ตหลายรายการในใบเดียวได้ และโหลดหน้าใหม่แล้วยังเห็น
- แก้ไข/ลบภายหลังได้จากหน้าเดียวกัน ขณะกดบันทึกแสดงสถานะรอและข้อผิดพลาด
- ข้ามบริษัท/สาขา หรือแก้ไข/ลบโน้ตผู้อื่นโดยไม่มีสิทธิ์ถูกปฏิเสธ
- เพิ่มและแก้ไขโน้ตในใบที่จ่ายหรือปิดแล้วได้ โดยไม่แตะสถานะและ hash ของใบเบิก
