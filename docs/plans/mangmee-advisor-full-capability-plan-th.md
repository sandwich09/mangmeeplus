# แผน: น้องมั่งมีเป็นที่ปรึกษาที่ทำได้ทุกอย่างตามสิทธิ์ (2026-10-15)

สถานะ: เริ่มรอบ 1 แล้ว · เจ้าของ: thawatchai · ควบคุม: Claude (Codex เขียนโค้ด)

## เป้าหมาย (คำของเจ้าของ 2026-10-15)
- น้องมั่งมีสร้าง แก้ ลบ และเข้าใจบริบทได้ทั้งระบบ ตามสิทธิ์ของผู้ใช้และสถานะของรายการ ตอบทุกคำถามเกี่ยวกับระบบเป็นภาษาคน ผู้ใช้ไม่ต้องรู้ว่าระบบทำงานอย่างไร
- เป็น advisor รู้ทุกฟีเจอร์ อธิบายได้ว่าเอกสารคืออะไร ทำไมต้องทำ สำคัญอย่างไร เราจ่าย/หักเท่าไหร่ (ใบสำคัญจ่าย 50 ทวิ ภงด.53 ภงด.3) และออกเอกสารให้โดยผู้ใช้กรอกน้อยที่สุด
- ขอบเขตฟีเจอร์สูงสุด = แพ็ก 1,999 (ENTERPRISE_1999: ชุด starter + wht_pnd53 + wht_50bis; ภงด.3 อยู่ระหว่างทำในอีก session)

## หลักที่ตกลงแล้ว
1. **เตรียมให้ คนกดเอง**: งานขั้นสุดท้าย (ยืนยัน อนุมัติ จ่าย ลบ ออกเอกสาร ซื้อแพ็กเกจ) น้องเตรียมให้ครบแล้วแสดงการ์ด/ลิงก์ รายการเปลี่ยนเมื่อผู้ใช้กดเองเท่านั้น ระบบเช็กสิทธิ์และสถานะซ้ำตอนกด (ขยายรูปแบบ confirm-card เดิม: `LineDraftUpdateUseCase.apply`, `LineReimbursementDraftService.confirm`) ไม่เปิด `AI_FINAL_MUTATION_ENABLED`
2. **ไม่ถามวน**: เดาค่าที่สมเหตุผลแล้วบอก เช่น ค่าบริการที่ให้แค่ยอดรวม = 1 งาน (ดู memory line-ai-assume-defaults)
3. **ไม่เงียบ ไม่ปัดไปเว็บ**: ทุกข้อความต้องได้คำตอบ ถ้าผู้ใช้มีสิทธิ์ ห้ามตอบ "ไปทำในเว็บ"
4. **จับคู่เมื่อแน่ใจเท่านั้น**: ใบเสร็จ + สลิปรวมอัตโนมัติเมื่อแชตเดียวกัน ยอดเท่ากันเป๊ะ เวลาใกล้กัน ใบเสร็จยังไม่มีหลักฐานจ่าย และมีผู้สมัครเพียงรายการเดียว นอกนั้นถามพร้อมปุ่ม รวมแล้วมีปุ่มแยกกลับ
5. ใช้ use-case เดิมของเว็บเสมอ (สิทธิ์ tenant สาขา สถานะ) AI Gateway เรียกผ่าน tool ที่เช็กสิทธิ์ ไม่แตะฐานข้อมูลตรง
