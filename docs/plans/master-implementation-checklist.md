# Master Implementation Checklist

## Rule

This is the canonical build order for WatchDog-BMS.

Before starting any feature work:

1. Open this checklist.
2. Pick the first unfinished item unless owner explicitly reorders.
3. Read linked spec and plan.
4. If spec or plan is missing, create it before code.
5. Update links and checkbox only after implementation and verification are done.

Web is the full Business OS workspace. LINE is the AI assistant, summary, alert, account-linking, and deep-link channel, with narrow draft-capture workflows only when a checklist item explicitly allows them, such as receipt upload in item 09.
