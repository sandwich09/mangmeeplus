```sh

psql -X -v ON_ERROR_STOP=1 -f docs/evidence/release-2026-10-04/post-release-checks.sql
```

Each file opens one repeatable-read, read-only transaction, sets UTC and local 30-second statement / 5-second lock timeouts, then rolls back. To run one labelled block, copy its complete `WITH`/`SELECT` statement(s) between the same `BEGIN`, `SET LOCAL` and `ROLLBACK` statements. On error the transaction is aborted: end it before another block. A timeout is missing evidence, never a zero. Do not raise timeouts on production without the deployer's review of load and lock waits.

Every result field is a numeric count, including guard/table counts. Internal keys and identifiers occur only in predicates/joins. There are no row samples, names, contact details, bank details, monetary amounts or timestamp outputs. Do not enable SQL statement logging that would print unrelated session data, append identifying queries, or publish underlying rows to explain a count. A nonzero warning goes to the restricted operator workflow; this evidence directory retains counts only.
