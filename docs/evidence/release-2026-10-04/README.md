To run one labelled block, copy its complete `WITH`/`SELECT` statement(s) between the same `BEGIN`, `SET LOCAL` and `ROLLBACK` statements. On error the transaction is aborted: end it before another block. A timeout is missing evidence, never a zero. Do not raise timeouts on production without the deployer's review of load and lock waits.
