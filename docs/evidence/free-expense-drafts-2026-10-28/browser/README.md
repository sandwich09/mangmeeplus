# ทดสอบกดใช้งานจริง: รายจ่ายฟรี 3 ใบ

วันที่ 28 ตุลาคม 2026 · สถานะ: ผ่านเส้นทางเว็บที่ระบุ หลังแก้ปัญหาที่พบ

ทดสอบด้วย Chrome ผ่าน Computer Use บนเว็บจาก working tree ปัจจุบันที่ `127.0.0.1:3080` ต่อ API จริง `127.0.0.1:3081` และ PostgreSQL/MinIO ในเครื่อง ฐานข้อมูลแยก `free_expense_ui_20261028` เป็นสำเนาข้อมูลสมมติ ไม่ใช้บัญชีหรือเอกสารลูกค้าจริง

ผลอ่าน OCR มาจาก HTTP fixture ที่รับเฉพาะ SHA256 ของ PNG ทดสอบ 4 ไฟล์ บัญชี สิทธิ์ การอัปโหลดไฟล์ การนับโควตา และการบันทึกร่างผ่านโค้ดจริง ไม่มีการดักหรือปลอม response ของเว็บ/API ตัว fixture ส่ง usage ว่างเพราะไม่มีการเรียกโมเดลจริง จึงไม่ใช่หลักฐานคุณภาพ OCR หรือราคาต้นทุนจริง

## ปัญหาที่แก้จากการกดจริง

1. เมนูและ export: จำกัด sidebar/หน้า list และ handler ตาม free mode; เก็บทางเข้าการตั้งค่าแพ็กเกจที่ permission อนุญาตไว้ ไม่เพิ่มสิทธิ์ API
2. ข้อความใบ 3: info notice ถูกซ่อนเมื่อมี AI summary; ทำข้อความครบสิทธิ์ให้แสดงต่อ และแก้ async allowance ให้รับจาก top-level contract
3. การรับข้อความหลังเปลี่ยนหน้า: React StrictMode รัน effect ซ้ำ ครั้งแรกอ่านและลบ session notice ครั้งที่สองล้าง state จึงหาย ใช้การ consume ครั้งเดียวต่อ expense และมี test จำลอง effect ซ้ำจริง
4. ชื่อสถานะ/ตัวกรอง: แสดง source ที่ยังไม่ยืนยันเป็นร่างใน free list โดยไม่เปลี่ยน stored workflow state

เกิด full reload ระหว่างแก้โค้ดเพราะ Next Fast Refresh ทำให้ตัวเลือกไฟล์ถูกล้างในรอบทดลอง จึงหยุด edits แล้วเลือกไฟล์/กดใหม่หลังโค้ดคงที่ ไม่มีการนับความพยายามที่ถูกยกเลิกเป็นผลผ่าน และตรวจ provider calls/DB แยกไว้

## ขอบเขตที่ยังไม่ได้พิสูจน์ด้วยหน้าจอ

ยังไม่ได้ส่ง LINE จริง, LINE/LIFF deep link ผ่านแอป, guest LINE, OCR provider จริง, PDF/HEIC/async worker ผ่าน UI, การสลับบริษัทหลายร้าน, การซื้อแพ็กเกจจริง หรือ UAT/Production deployment มือถือเป็น Chrome viewport ไม่ใช่อุปกรณ์จริง

ออกจากบัญชีทดสอบและคืน viewport หลังทดสอบ เก็บภาพและข้อมูลสมมติไว้สำหรับตรวจย้อนหลัง ไม่ commit/push/deploy

หยุด API/Web/OCR fixture และ task PostgreSQL/Redis/MinIO หลังเก็บหลักฐานแล้ว เก็บฐานข้อมูลสมมติไว้ใน container ที่หยุดอยู่; ย้อนเฉพาะ path .next-free-expense-ui ที่ Next สร้างใน next-env.d.ts กลับไปใช้ .next/dev ตาม local development เดิม ไม่ reset ไฟล์งานค้างอื่น
