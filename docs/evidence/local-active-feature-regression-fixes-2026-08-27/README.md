# ผลแก้ regression ฟีเจอร์พื้นฐาน — 27 สิงหาคม 2569

แก้โค้ดตามรายงาน R01–R12 และทดสอบบนสำเนาฐานข้อมูล local จริงแล้ว ไม่เปิดฟีเจอร์เพิ่ม ไม่เปลี่ยนข้อมูลเก่าที่ไม่ทราบสาขา และยังไม่ใช่หลักฐานว่า AI/OCR อ่านใบเสร็จจริงถูกต้อง

## สิ่งที่แก้และหลักฐาน

| ประเด็น | ผลแก้ / วิธีพิสูจน์ |
| --- | --- |
| R01 แหล่งที่มาสาขา | รายการใหม่ต้องมีสาขาที่ใช้งานได้และอยู่ในสิทธิ์; งานต่อเนื่องใช้สาขาของเอกสารต้นทาง ทั้ง API และฟอร์ม รายการเก่า 157 ใบยังรอหลักฐานจากเจ้าของ ไม่เดาหรือย้ายข้อมูล |
| R02 หลักฐาน/ส่งออกไม่ตามสาขา | กรองสาขาถึง API และสิทธิ์; Excel ระบุรหัสสาขาจริง; เทียบ ID/จำนวนรายการของ list, evidence, export ตรงกัน; ป้องกันผลเก่าจากการโหลดสาขาก่อนหน้า; โหลดครบทุกหน้าก่อนรวมยอด |
| R03 บันทึกไม่ผ่าน | สำเนา local ใช้การอนุมัติรุ่นโค้ดตามกระบวนการเดิม ไม่ข้าม guard; บันทึกฉบับร่างและอ่านกลับสำเร็จจริงทั้งสองขนาดจอ; บันทึกไม่สำเร็จ focus ข้อความไทยและเก็บข้อมูลที่กรอก |
| R04 VAT | เปลี่ยนเป็น “VAT ตามเอกสาร” พร้อมบอกว่ายังไม่ใช่ยอดใช้สิทธิ์ ไม่เปลี่ยนนโยบายภาษี |
| R05 ยอดคนละความหมาย | แยกยอดเอกสารรับเข้ารวมที่ยังไม่ยืนยัน กับค้างจ่ายเฉพาะเอกสารยืนยัน; ระบุเกณฑ์วันที่/ช่วงเวลา และทศนิยมสองตำแหน่ง |
| R06 การ์ด dashboard | ลิงก์รอตรวจ/ค้างจ่ายใช้ทุกช่วงเวลา; ยืนยันแล้วใช้ช่วงวันที่เอกสารตามการ์ด เทสรอตรวจ 105 ตรงกันทั้งการ์ดกับหน้าปลายทาง |
| R07 เมนูขายหาย | เปิดทางเข้าเมนูที่มีอยู่แล้วตาม permission และสวิตช์เดิม ไม่เปิดฟีเจอร์ใหม่ |
| R08 มือถือ | ปุ่มอัปโหลด/บันทึกอยู่ก่อน รายการสรุปและส่งออกพับได้ รายการแรกอยู่ประมาณ 750 px แทนเดิมประมาณ 1,228 px; ไม่ล้นความกว้างจอ 390 px ในเส้นทางที่ตรวจ |
| R09 ภาษา/สาขา | ชื่อสาขามือถืออ่านแยกได้; ชื่อเมนูพนักงานและบทบาทไทยสอดคล้องกัน; ลดศัพท์ในฟอร์มพื้นฐาน; เบิกจ่ายแสดงบาท/พ.ศ.; ไม่เรียกสถานะปิดสมุดรายวันว่า “รอเปิดใช้” |
| R10 ประวัติเมื่อปิดฟีเจอร์ | เบิกจ่ายอธิบายการเก็บประวัติ/ไม่รับรายการใหม่; คู่มือไม่สัญญาว่า LINE เปิดอยู่; notification รายงานเจาะจงไฟล์ต้นทาง หากไม่พบต้องบอก ไม่พาไปไฟล์อื่นแทน |
| R11 ความพร้อมส่งบัญชี | “ยืนยันแล้ว” ไม่เท่ากับ “ข้อมูลครบ” แสดงคำเตือนและวิธียกเลิก/บันทึกใหม่ ไม่ปลดล็อกเอกสารยืนยันให้แก้ตรง ๆ |
| R12 พนักงานใหม่ | ไม่เลือกบทบาทบัญชีให้เอง; ใช้สาขาที่กำลังทำงานหรือสาขาเดียว หากอยู่ทุกสาขาให้เลือก ไม่สร้างพนักงาน/ให้สิทธิ์ใครระหว่างเทส |

## ข้อจำกัดที่ยังไม่ปิด

1. ข้อมูลเดิม 157 รายการไม่มีสาขาที่พิสูจน์ได้ ยอดทุกสาขาจึงยังไม่อาจแจกแจงเท่าผลรวมรายสาขาจนกว่าจะได้แหล่งที่มา ห้ามตีความว่าโค้ดป้องกันรายการใหม่แก้ข้อมูลเก่าแล้ว
2. MODEL_PROVIDER ปิดและไม่มี worker อ่านใบเสร็จจริงในชุดพิสูจน์นี้ จึงพิสูจน์การรับไฟล์/จัดสาขา ไม่ใช่ความฉลาด/ความเร็ว/ความถูกต้อง AI และไม่เปิด LINE หรือฟีเจอร์ที่ปิดไว้
3. ไม่ใช่ UAT/Production release ไม่ merge main ไม่แก้ cloud หรือสวิตช์ 16 ON / 44 OFF
4. การนำโค้ดที่ผ่านไปเปิดบน local เดิม 3000/3003 และหลักฐานการบันทึกของรุ่นที่ commit จะเติมในหัวข้อถัดไปก่อนส่งงาน
