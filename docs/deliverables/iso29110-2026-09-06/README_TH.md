# ชุดเอกสาร ISO IEC 29110 ของบริษัท มั่งมียั่งยืน จำกัด

จัดทำ 6 กันยายน 2569 เอกสารส่วนที่ขาดพร้อมข้อมูลที่ตรวจพบจริง รอชื่อผู้รับผิดชอบ การลงนาม และหลักฐานที่ระบุในรายการก่อนยื่น

1. เปิด MANGMEE_ISO29110_Documents.docx เพื่อกรอกชื่อและตำแหน่ง ตรวจเนื้อหา และลงนามด้วยวันที่จริง มี CR กรณีจริง แบบ CR เปล่า คู่มือพัฒนา 2 หน้า บันทึก release/maintenance และแบบ baseline/รับมอบ
2. เปิด MANGMEE_ISO29110_Registers.xlsx เพื่อใช้ทะเบียน CR, Deployment, Maintenance, Traceability, Evidence และรายการก่อนยื่น ช่องสีเหลืองให้ผู้รับผิดชอบเติมตามข้อเท็จจริง
3. เปิด evidence/ ตามรหัสในทะเบียน ไฟล์ต้นทางถูกเก็บเป็นสำเนา ณ วันที่จัดชุด ตรวจรายการและ SHA-256 ได้จาก evidence-manifest.json
4. ตรวจรายการก่อนยื่นให้ครบตามขอบเขตหน่วยรับรอง ห้ามลบข้อจำกัดหรือเปลี่ยนสถานะเป็นอนุมัติ/รับมอบเพียงเพราะจัดเอกสารเสร็จ

## สิ่งที่ต้องทำโดยผู้รับผิดชอบ

- ยืนยันชื่อบุคคลและอำนาจลงนาม รวมถึงวันเริ่มใช้ SOP
- ยืนยันโครงการนำร่อง/แผนที่อนุมัติ และผู้รับมอบ
- แนบการอนุมัติ CR เดิมหากมี มิฉะนั้นคงข้อเท็จจริงว่าไม่พบ
- เชื่อม release รุ่นเดียวกับกรณี VAT แล้วทำ UAT/รับมอบจริง; deployment วันที่ 10 สิงหาคมเป็นอีกเหตุการณ์ ไม่ใช่หลักฐานเผยแพร่งาน VAT วันที่ 27 สิงหาคม
- ระบุผู้รับผิดชอบและผลยืนยันปิด Maintenance

GitHub run success ยืนยันการทำงานของ workflow ไม่ได้แทน signed deployment artifacts หรือการรับมอบทางธุรกิจ บันทึกทดสอบเดิมมีข้อจำกัด local/synthetic ตามต้นทาง ไม่มีการรันทดสอบหรือ deploy ใหม่ในการจัดชุดนี้

ไฟล์นี้เป็นคู่มือใช้ชุดเอกสาร มิใช่คำรับรองว่าผ่าน ISO หรือได้รับอนุมัติเข้าโครงการแล้ว
